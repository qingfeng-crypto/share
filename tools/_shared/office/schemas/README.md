# OOXML Schemas

本目录用于存放 OOXML (Office Open XML) 的 XSD 架构定义文件，供 docx/pdf/xlsx 工具链验证时使用。

## 子目录

| 目录 | 说明 |
|------|------|
| `ecma/` | ECMA-376 标准 XSD |
| `ISO-IEC29500-4_2016/` | ISO/IEC 29500-4:2016 标准 XSD |
| `mce/` | Markup Compatibility and Extensibility XSD |
| `microsoft/` | Microsoft 扩展 XSD |
