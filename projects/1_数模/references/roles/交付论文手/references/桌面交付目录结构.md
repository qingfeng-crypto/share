# 项目根目录交付结构（轻量版）

默认交付到**项目根目录**（用户当前工作目录），文件名格式 `Q1_交付.md`、`Q2_交付.md` 等。

该目录是中间交接物：

- 不参与 git
- 不作为正式比赛最终提交目录（最终提交物为论文 PDF + 支撑材料.zip）

## 逐子问题轻量交付结构

每个子问题完成后，生成一份轻量交付文件到项目根目录：

```text
项目根目录/
├── Q1_交付.md
├── Q2_交付.md
├── Q3_交付.md
├── Q4_交付.md
└── ...（按子问题数量生成）
```

每份 `QN_交付.md` 包含 5 项内容，见 `逐子问题交付模板.md`。

## 设计意图

1. 逐子问题交付，不必等全部计算完成。
2. 每份交付独立，论文手拿到即可写对应章节。
3. 模型说明、公式变量、术语表由建模手直接交付论文手，不经过本角色。
4. 与 `支撑材料/` 文件夹同处项目根目录，论文手在同一位置即可查看所有材料。
