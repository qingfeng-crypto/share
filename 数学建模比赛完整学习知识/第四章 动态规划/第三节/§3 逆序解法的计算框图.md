# §3 逆序解法的计算框图

> 来源：运筹学第四章动态规划六小节精简整理（原节约 60%）。

## 3.1 逆序解法概述

逆序解法是从终点开始，逆着阶段的顺序逐步向前求解。对于**自由终端、固定始端、指标函数取和**的形式：

```
f_k(x_ki) = v_k(x_ki, u_ki^(j)) + f_{k+1}(T_k(x_ki, u_ki^(j)))
```

## 3.2 计算步骤

1. 由 `k=n` 开始，逐次向前计算 `f_k(x_ki)`，`k=n-1,…,1`；
2. 对每个状态 `x_ki`，枚举所有允许决策 `u_ki^(j)`，计算候选值；
3. 取最优决策 `u_ki*(x_ki)`，得到最优值 `f_k(x_ki)`；
4. 计算至 `f_1(x_1*)` 即为全过程最优值；
5. 从 `x_1*` 出发，根据最优决策序列回溯得到最优路径。

## 3.3 计算框图结构（左右两栏）

- **左栏（函数序列递推）**：`k=n → k=1`，逐步算出最优值函数 `f_k(x_ki)`。
- **右栏（决策回溯）**：从 `x_1*` 出发，根据最优决策序列回溯最优路径。

**存储需求**：
- `f_k(x_ki)`：用于计算 `f_{k-1}`；
- `u_k*(x_ki)`：用于右栏回溯。

## 数模衔接

- 编码实现用字典/数组存储 `f_k` 与 `u_k*` 两张表，先递推填满左栏，再回溯右栏。
- 状态空间大时注意**维数灾难**（计算量随阶段数指数增长），可结合记忆化或状态离散化。
