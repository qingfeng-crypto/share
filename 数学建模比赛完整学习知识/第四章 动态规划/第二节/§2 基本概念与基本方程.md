# §2 基本概念与基本方程

> 来源：运筹学第四章动态规划六小节精简整理（原节约 65%）。

## 一、基本概念

| 概念 | 符号 | 说明 |
|------|------|------|
| 阶段 Stage | `k = 1,2,…,n` | 按时间或空间划分的阶段 |
| 状态 State | `s_k`，集合 `S_k` | 阶段初的客观条件，须满足无后效性 |
| 决策 Decision | `u_k(s_k)`，集合 `D_k(s_k)` | 给定状态下选达下一状态的动作 |
| 策略 Policy | `p_{k,n}(s_k)` | 各阶段决策组成的序列 |
| 状态转移 | `s_{k+1} = T_k(s_k, u_k)` | 状态随决策的变化规律 |
| 阶段指标 | `v_k(s_k, u_k)` | 第 k 阶段的效益（或代价） |
| 最优值函数 | `f_k(s_k)` | 从 `s_k` 到终点的最优指标值 |

## 二、基本方程（Bellman 方程，逆序、求和型）

```
f_k(s_k) = opt { v_k(s_k, u_k) + f_{k+1}(s_{k+1}) }
边界：f_{n+1}(s_{n+1}) = 0（或终端条件给定）
```

- **求解方向**：从 `k = n` 向前递推至 `k = 1`（**逆序求解**）。
- 每阶段对所有可能状态 `s_k` 计算 `f_k(s_k)` 并记录最优决策 `u_k*(s_k)`。
- 最终最优值 `= f_1(s_1)`；最优策略由 `s_1` 沿记录的最优决策**正向回溯**得到。

## 三、解题步骤

1. 划分阶段，定义阶段变量 `k`；
2. 确定状态变量 `s_k` 及取值范围 `S_k`；
3. 确定决策变量 `u_k` 及允许决策集 `D_k(s_k)`；
4. 写出状态转移方程 `s_{k+1} = T_k(s_k, u_k)`；
5. 写出阶段指标 `v_k(s_k, u_k)`，确定递推方程（Bellman 方程）；
6. 从终点逆推逐段计算 `f_k(s_k)`，记录最优决策；
7. 从起点正向回溯，得到最优策略与最优值。
