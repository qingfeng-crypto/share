# §4 动态规划与静态规划的关系

> 来源：运筹学第四章动态规划六小节精简整理（原节约 65%）。

## 4.1 本质联系

动态规划与静态规划（线性规划、非线性规划等）本质上都是在若干约束条件下的函数极值问题，两种规划在很多情况下**原则上可以相互转换**。

## 4.2 用动态规划解静态规划问题

某些静态规划问题只要**人为地引入时间因素**，把它视为多阶段决策过程，就可以用动态规划方法方便地求解。

**示例**：求解 `max Σ g_k(u_k)`，s.t. `Σ u_k = a, u_k ≥ 0`

- 按变量 `u_k` 的序号划分阶段（共 n 段），取 `x_1 = a`；
- 状态转移方程：`x_{k+1} = x_k - u_k`；
- 最优值函数的基本方程：

```
f_k(x_k) = max_{0≤u_k≤x_k} [ g_k(u_k) + f_{k+1}(x_{k+1}) ]
```

## 4.3 动态规划的优缺点

**优点**：
- 能够得到**全局最优解**（而某些迭代方法只能得到局部最优）；
- 可以处理具有无后效性的多阶段决策问题。

**缺点**：
- 没有统一的数学模型和标准求解格式，需要针对具体问题建立模型；
- **维数灾难**：当状态变量较多时，计算量随阶段数呈指数增长。

## 数模衔接

- 静态资源分配（总量约束、求最大收益）既可用线性/整数规划（`pulp`/`cvxpy`），也可用 DP。
- 连续高维用规划求解器更快；离散阶段化、需全局最优且状态可控时用 DP。
