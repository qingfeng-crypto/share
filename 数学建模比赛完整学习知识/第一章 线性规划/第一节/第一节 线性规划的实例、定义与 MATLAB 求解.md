# 第一节 线性规划的实例、定义与 MATLAB 求解

## 一、线性规划的基本思想

线性规划（Linear Programming，LP）研究这样一类问题：在一组线性约束条件限制下，求一个线性目标函数的最大值或最小值。

典型应用是生产计划问题。企业需要根据产品利润、设备工时、原材料和市场需求等条件，确定各产品的生产数量，使总利润最大或总成本最小。

线性规划模型的核心组成部分包括：

- **决策变量**：需要由决策者确定的未知量，例如各产品的生产数量；
- **目标函数**：需要最大化或最小化的线性函数，例如总利润或总成本；
- **约束条件**：由资源、需求、技术或政策条件形成的线性等式或不等式；
- **变量取值范围**：通常包括非负约束，也可以包括上下界。

## 二、生产计划实例

某机床厂生产甲、乙两种机床。每台甲机床销售后的利润为 4000 元，每台乙机床销售后的利润为 3000 元。生产 1 台甲机床需要使用 A、B 两台机器，分别加工 2 小时和 1 小时；生产 1 台乙机床需要使用 A、B、C 三台机器，各加工 1 小时。每天可用于加工的机器总工时分别为：A 机器 10 小时、B 机器 8 小时、C 机器 7 小时。

要求确定甲、乙两种机床的日产量，使每天总利润最大。

### 1. 决策变量

设：

- \(x_1\)：每天生产的甲机床数量；
- \(x_2\)：每天生产的乙机床数量。

### 2. 目标函数

以千元为利润单位，每天总利润为：

\[
z=4x_1+3x_2.
\]

目标是最大化总利润：

\[
\max z=4x_1+3x_2.
\]

### 3. 约束条件

A 机器工时约束：

\[
2x_1+x_2\leq 10.
\]

B 机器工时约束：

\[
x_1+x_2\leq 8.
\]

C 机器工时约束：

\[
x_2\leq 7.
\]

生产数量非负：

\[
x_1\geq0,\qquad x_2\geq0.
\]

### 4. 完整模型

\[
\begin{aligned}
\max\quad &z=4x_1+3x_2\\
\text{s.t.}\quad
&2x_1+x_2\leq10,\\
&x_1+x_2\leq8,\\
&x_2\leq7,\\
&x_1,x_2\geq0.
\end{aligned}
\]

该模型中的目标函数和所有约束均为变量的一次函数，因此属于线性规划模型。

如果生产数量必须是完整台数，还应增加整数约束；本例按连续线性规划处理。

## 三、线性规划的 MATLAB 标准形式

MATLAB 的 `linprog` 默认求解最小化问题。其常用标准形式为：

\[
\begin{aligned}
\min\quad &c^\mathsf{T}x\\
\text{s.t.}\quad
&Ax\leq b,\\
&A_{\mathrm{eq}}x=b_{\mathrm{eq}},\\
&lb\leq x\leq ub.
\end{aligned}
\]

其中：

- \(x\) 是 \(n\) 维决策变量列向量；
- \(c\) 是目标函数系数列向量；
- \(A\) 和 \(b\) 描述不等式约束；
- \(A_{\mathrm{eq}}\) 和 \(b_{\mathrm{eq}}\) 描述等式约束；
- `lb` 和 `ub` 分别是变量下界和上界。

### 最大化问题的转换

若原问题为：

\[
\max c^\mathsf{T}x,
\]

则可改写为：

\[
\min(-c)^\mathsf{T}x.
\]

若约束为 \(Ax\geq b\)，则两边同时乘以 \(-1\)：

\[
Ax\geq b
\quad\Longleftrightarrow\quad
-Ax\leq-b.
\]

## 四、生产计划实例的矩阵表达

生产计划模型写成 MATLAB 输入形式：

\[
c=\begin{bmatrix}-4\\-3\end{bmatrix},\qquad
A=\begin{bmatrix}2&1\\1&1\\0&1\end{bmatrix},\qquad
b=\begin{bmatrix}10\\8\\7\end{bmatrix}.
\]

非负约束写成：

\[
lb=\begin{bmatrix}0\\0\end{bmatrix},
\qquad ub=\begin{bmatrix}\infty\\\infty\end{bmatrix}.
\]

MATLAB R2024b 求解代码：

```matlab
% 目标函数：最大化 4*x1 + 3*x2
% linprog 默认求最小化，因此取负号
f = [-4; -3];

% 不等式约束 A*x <= b
A = [
    2 1;  % A 机器工时
    1 1;  % B 机器工时
    0 1   % C 机器工时
];
b = [10; 8; 7];

% 等式约束为空
Aeq = [];
beq = [];

% 非负约束
lb = [0; 0];
ub = [];

[x, fval, exitflag, output, lambda] = linprog( ...
    f, A, b, Aeq, beq, lb, ub);

if exitflag > 0
    maxProfit = -fval;
    resourceUsed = A * x;
    resourceRemain = b - resourceUsed;
    utilization = resourceUsed ./ b;

    fprintf('甲机床产量：%.4f 台\n', x(1));
    fprintf('乙机床产量：%.4f 台\n', x(2));
    fprintf('最大利润：%.4f 千元\n', maxProfit);

    disp('资源使用量：');
    disp(resourceUsed);
    disp('资源剩余量：');
    disp(resourceRemain);
    disp('资源利用率：');
    disp(utilization);
else
    fprintf('求解未成功，exitflag = %d\n', exitflag);
    disp(output.message);
end
```

## 五、线性规划解的基本概念

### 1. 可行解

满足所有约束条件的决策变量向量称为可行解。

### 2. 可行域

所有可行解构成的集合称为可行域，记为 \(R\)。

线性规划的可行域是若干个半空间、等式约束集合和变量边界的交集，因此是一个凸多胞形；可行域也可能是空集。

### 3. 最优解

使目标函数取得最大值或最小值的可行解称为最优解，对应的目标函数值称为最优值。

### 4. 无解、无界与有限最优解

- **无解**：可行域为空，不存在满足全部约束的方案；
- **无界**：可行域非空，但目标函数可以沿可行方向无限改善，不存在有限最优值；
- **有限最优解**：存在可行方案，并且目标函数在可行域上取得有限最大值或最小值。

## 六、线性规划的图解法

当决策变量只有两个时，可以在平面上绘制每个约束对应的边界直线，并确定满足全部约束的可行区域。

对于目标函数：

\[
z=c_1x_1+c_2x_2,
\]

固定一个目标值 \(z\) 后，满足该等式的点构成一条目标函数等值线。改变 \(z\) 时，得到一族相互平行的等值线。

求最大值时，沿目标函数增加的方向移动等值线，直到等值线最后接触可行域；求最小值时，沿目标函数减少的方向移动。

对于本节生产计划实例，最优顶点为：

\[
x^*=\begin{bmatrix}2\\6\end{bmatrix},
\qquad z^*=26.
\]

该结果对应每天生产 2 台甲机床和 6 台乙机床，最大利润为 26 千元。

### 顶点最优性

若线性规划存在有限最优解，则至少存在一个可行域极点，使目标函数取得最优值。二维情况下，极点通常表现为可行域边界直线的交点；在高维空间中，使用凸集和极点的定义进行推广。

## 七、凸集与极点

### 1. 凸集

区域 \(R\) 称为凸集，是指对任意 \(x_1,x_2\in R\) 和任意 \(\lambda\in[0,1]\)，都有：

\[
\lambda x_1+(1-\lambda)x_2\in R.
\]

也就是说，凸集中任意两点的连线仍然完全位于该集合内。

### 2. 极点

设 \(R\) 为凸集。如果不存在两个不同的点 \(x_1,x_2\in R\) 以及 \(\lambda\in(0,1)\)，使得：

\[
x=\lambda x_1+(1-\lambda)x_2,
\]

则称 \(x\) 为凸集 \(R\) 的极点。

线性规划的可行域是凸集；当存在有限最优值时，可以在可行域极点中寻找最优解。这是单纯形法和许多线性规划算法的重要几何基础。

## 八、绝对值目标函数的线性化

含绝对值的目标函数有时可以通过引入非负辅助变量转化为线性规划。

对每个变量 \(x_i\)，引入：

\[
x_i=u_i-v_i,
\qquad u_i\geq0,\quad v_i\geq0.
\]

在最小化目标中，可以用：

\[
|x_i|=u_i+v_i.
\]

因此问题：

\[
\min\sum_{i=1}^{n}|x_i|
\]

约束：

\[
Ax\leq b
\]

可转化为：

\[
\begin{aligned}
\min\quad &\sum_{i=1}^{n}(u_i+v_i)\\
\text{s.t.}\quad &A(u-v)\leq b,\\
&u\geq0,\quad v\geq0.
\end{aligned}
\]

这里用到了：

\[
u_i=\frac{|x_i|+x_i}{2},
\qquad
v_i=\frac{|x_i|-x_i}{2}.
\]

## 九、MATLAB 求解后的结果检查

调用求解器后，不能只读取变量和目标值，还应检查：

1. `exitflag` 是否表示求解成功；
2. `A*x-b` 是否满足不等式约束；
3. `Aeq*x-beq` 是否满足等式约束；
4. `lb <= x <= ub` 是否成立；
5. 资源使用量 `A*x`、资源剩余量 `b-A*x` 和利用率是否合理；
6. 目标函数值是否与原始最大化或最小化问题的方向一致。

## 十、知识总结

线性规划的完整处理链条为：

```text
实际问题
→ 确定决策变量
→ 建立目标函数
→ 建立约束条件
→ 写成数学模型
→ 转换为 MATLAB 标准形式
→ 调用 linprog 求解
→ 检查可行性与求解状态
→ 解释最优方案和最优值
```

本节建立了线性规划的基本概念、生产计划建模方法、图解法几何解释、MATLAB 标准形式以及绝对值目标函数的线性化方法。
