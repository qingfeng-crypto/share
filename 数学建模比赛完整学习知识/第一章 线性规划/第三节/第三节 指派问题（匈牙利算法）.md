# 第三节 指派问题（匈牙利算法）

## 一、问题描述

有 \(n\) 个人和 \(n\) 项工作，第 \(i\) 个人完成第 \(j\) 项工作需要时间 \(c_{ij}\)。每人恰好做一项工作，每项工作恰好由一人完成。目标：使总耗时最少。

指派问题是运输问题的特例（\(m=n\)、供给量 \(a_i=1\)、需求量 \(b_j=1\)），也是 0-1 规划。

## 二、数学模型

引入 0-1 变量 \(x_{ij}\)：\(x_{ij}=1\) 表示第 \(i\) 人做第 \(j\) 项工作，否则为 0。

\[
\begin{aligned}
\min\quad &z=\sum_{i=1}^{n}\sum_{j=1}^{n}c_{ij}x_{ij}\\
\text{s.t.}\quad
&\sum_{j=1}^{n}x_{ij}=1,\qquad i=1,\ldots,n,\\
&\sum_{i=1}^{n}x_{ij}=1,\qquad j=1,\ldots,n,\\
&x_{ij}\in\{0,1\}.
\end{aligned}
\]

约束矩阵是全单位模矩阵（totally unimodular），因此可放松为 \(x_{ij}\geq0\) 求解，线性规划最优解自然给出整数解。

## 三、匈牙利算法

匈牙利算法是求解指派问题的经典算法，核心思想：在系数矩阵的行列上加减同一个常数，最优指派方案不变。通过反复变换，使矩阵中出现足够多的零元素，从而找到"零耗时"的指派方案。

### 算法步骤

1. **行归约**：每行减去该行最小值。
2. **列归约**：每列减去该列最小值。
3. **覆盖检验**：用最少的直线覆盖所有零元素。
   - 若直线数 \(=n\)，已找到最优解，在所有零中选出 \(n\) 个不同行不同列的零即为最优指派。
   - 若直线数 \(<n\)，进入下一步。
4. **矩阵调整**：在未覆盖的区域中找最小值 \(m\)，对未覆盖元素减 \(m\)，对交叉点元素加 \(m\)。
5. 重复第 3 步和第 4 步，直到直线数 \(=n\)。

简单理解：通过"价格调整"让某些人做某项工作的成本降为零，然后找一组人人都能"免费"做一项不同工作的方案。

## 四、MATLAB 求解（线性规划法）

由于约束矩阵全单位模，用 `linprog` 即可（无需 `intlinprog`）。设费用矩阵 \(C_{n\times n}\)：

```matlab
% 费用矩阵 C(i,j)：第 i 人做第 j 项工作的耗时
n = size(C, 1);

% 目标函数：最小化总耗时
f = C(:);  % 按列展开

% 等式约束：每人做一项、每项一人做
% 每人约束：n 行，每行对应一个人
Aeq_person = kron(eye(n), ones(1, n));
% 每项约束：n 行，每行对应一项工作
Aeq_task = kron(ones(1, n), eye(n));
Aeq = [Aeq_person; Aeq_task];
beq = ones(2 * n, 1);

% 非负约束（全单位模保证自动取 0 或 1）
lb = zeros(n * n, 1);
ub = [];

[x, fval, exitflag] = linprog(f, [], [], Aeq, beq, lb, ub);

if exitflag <= 0
    error('指派问题求解失败');
end

% 还原为指派矩阵
assign = reshape(x, n, n).';
totalTime = fval;

% 提取指派方案
[~, jobIdx] = max(assign, [], 2);
fprintf('最小总耗时：%.6f\n', totalTime);
for i = 1:n
    fprintf('第 %d 人 -> 第 %d 项工作（耗时 %.2f）\n', ...
        i, jobIdx(i), C(i, jobIdx(i)));
end
```

### 与 `intlinprog` 的等价性

若显式写为 0-1 变量，可改用 `intlinprog`：

```matlab
% 所有变量均为 0-1
intcon = 1:n*n;
[x, fval, exitflag] = intlinprog(f, intcon, ...
    [], [], Aeq, beq, lb, ub);
```

由于全单位模性质，两种方法给出相同结果，但 `linprog` 更快。

## 五、MATLAB 匈牙利算法实现

以下实现供学习参考，实际使用直接调 `linprog` 即可：

```matlab
function [assign, totalCost] = hungarian(C)
    % 匈牙利算法求解指派问题
    n = size(C, 1);
    u = C;
    
    % 行归约
    u = u - min(u, [], 2);
    % 列归约
    u = u - min(u, [], 1);
    
    % 迭代标记与覆盖方案
    while true
        % 标记零元素（行、列两个方向）
        rowCovered = false(n, 1);
        colCovered = false(n, 1);
        starred = false(n);
        
        % 每行若只有一个零，标记该行该列
        for i = 1:n
            zeroCols = find(u(i, :) == 0 & ~colCovered');
            for j = zeroCols
                if ~colCovered(j)
                    starred(i, j) = true;
                    colCovered(j) = true;
                    break;
                end
            end
        end
        
        % 覆盖已标记的列
        rowCovered(:) = false;
        colCovered(:) = any(starred, 1);
        
        uncoveredZeros = true;
        while uncoveredZeros
            [r, c] = find(u == 0 & ~rowCovered & ~colCovered', 1);
            if isempty(r)
                uncoveredZeros = false;
                continue;
            end
            
            % 沿列找 starred
            sc = find(starred(r, :), 1);
            if isempty(sc)
                % 增广路径
                starred(r, c) = true;
                rowCovered(r) = true;
                colCovered(c) = false;
                continue;
            end
            rowCovered(r) = true;
            colCovered(sc) = false;
        end
        
        % 检查是否找到 n 个 star
        if sum(starred, 'all') == n
            break;
        end
        
        % 调整矩阵：未覆盖区域找最小值
        uncovered = u(~rowCovered, ~colCovered);
        m = min(uncovered, [], 'all');
        u(~rowCovered, ~colCovered) = u(~rowCovered, ~colCovered) - m;
        u(rowCovered, colCovered) = u(rowCovered, colCovered) + m;
    end
    
    [assignRows, assignCols] = find(starred);
    [~, idx] = sort(assignRows);
    assignCols = assignCols(idx);
    assign = [assignRows, assignCols];
    totalCost = sum(C(sub2ind(size(C), assignRows, assignCols)));
end
```

调用示例：

```matlab
C = [2 10 9; 3 7 5; 8 4 6];
[assign, cost] = hungarian(C);
fprintf('最优指派方案：\n');
for i = 1:size(assign, 1)
    fprintf('第 %d 人 -> 第 %d 项工作\n', assign(i, 1), assign(i, 2));
end
fprintf('最小总耗时：%d\n', cost);
```

## 六、非方阵处理

实际中人数和任务数可能不相等，需要补全为方阵：

- **人数 > 任务数**（\(m>n\)）：添加 \(m-n\) 个虚拟任务，费用为 0；虚拟任务意味着"该人闲置"。
- **任务数 > 人数**（\(n>m\)）：添加 \(n-m\) 个虚拟人，费用为 0；虚拟人意味着"该任务无人做"。

示例：

```matlab
% 5 人 3 项工作：补 2 个虚拟任务
C = [5 8 3; 6 4 2; 7 9 1; 3 5 4; 8 6 7];
[m, n] = size(C);
if m > n
    C = [C, zeros(m, m - n)];
elseif n > m
    C = [C; zeros(n - m, n)];
end
% 此时 C 为方阵，可调用 linprog 或匈牙利算法
```

## 七、结果检查

得到指派方案后，至少检查：

1. 每人是否恰好分配一项工作（\(\sum_j x_{ij}=1\)）；
2. 每项工作是否恰好分配给一人（\(\sum_i x_{ij}=1\)）；
3. 所有 \(x_{ij}\) 是否为 0 或 1；
4. 总耗时是否等于 \(\sum_i\sum_j c_{ij}x_{ij}\)；
5. 若使用匈牙利算法，是否与 `linprog` 得到相同的最优值。

## 八、知识总结

指派问题的建模与求解流程：

```text
确定人数与任务数 → 整理费用矩阵
→ 检查是否方阵（非方则补虚拟人/任务）
→ 建立 0-1 规划模型
→ 选择求解方法（linprog / 匈牙利算法）
→ 提取指派方案 → 检查约束是否满足
→ 输出总耗时和指派结果
```

指派问题是运输问题的特例，匈牙利算法是"化繁为简"的经典运筹学思路。实际比赛中，当人数和任务数 ≤ 几百时，直接用 `linprog` 即可，无需手动实现匈牙利算法。
