# 第五节 投资的收益和风险

## 一、问题描述

市场上有 \(n\) 种资产可供投资，例如股票、债券或基金。已知：

- 资产 \(i\) 的平均收益率为 \(r_i\)；
- 资产 \(i\) 的风险损失率为 \(q_i\)；
- 资产 \(i\) 的交易费率为 \(p_i\)；
- 投资总资金为 \(M\)。

设 \(x_i\) 表示投入资产 \(i\) 的资金金额，则：

\[
x_i\geq0,\qquad \sum_{i=1}^{n}x_i=M.
\]

资产 \(i\) 的净收益系数为：

\[
g_i=r_i-p_i.
\]

总净收益为：

\[
R(x)=\sum_{i=1}^{n}g_i x_i.
\]

如果用单个资产的风险损失额最大值表示组合风险，则总体风险为：

\[
Q(x)=\max_{1\leq i\leq n}\{q_i x_i\}.
\]

收益最大化和风险最小化通常是相互竞争的目标，但“收益越高风险一定越高”不是数学定理，实际关系需要由数据和模型计算得到。

## 二、风险的线性化

总体风险含有最大值函数，直接写入线性规划不够方便。引入辅助变量 \(t\)，要求：

\[
t\geq q_i x_i,
\qquad i=1,2,\ldots,n.
\]

于是：

\[
t\geq \max_i\{q_i x_i\}=Q(x).
\]

当目标函数最小化 \(t\) 或对 \(t\) 施加上界时，最优解会自动使 \(t=Q(x)\)。因此，最大风险目标被转化为一组线性不等式。

变量含义为：

- \(x_i\)：资产 \(i\) 的投资金额；
- \(t\)：组合中最大的单项风险损失额。

## 三、三种单目标化模型

多目标规划通常不能直接交给普通线性规划求解器，需要把一个目标转化为约束，或把多个目标合成为一个目标。

### 模型一：固定风险上限，最大化收益

给定允许的风险上限 \(a\)，其中 \(a\geq0\)。模型为：

\[
\begin{aligned}
\max\quad &\sum_{i=1}^{n}g_i x_i\\
\text{s.t.}\quad
&\sum_{i=1}^{n}x_i=M,\\
&q_i x_i\leq a,\qquad i=1,\ldots,n,\\
&x_i\geq0.
\end{aligned}
\]

这里的 \(a\) 是风险损失金额上限。如果题目把风险上限定义为占总资金的比例 \(\alpha\)，则应写成：

\[
q_i x_i\leq \alpha M.
\]

不能混用“金额上限”和“比例上限”两种定义。

### 模型二：固定最低收益，最小化风险

给定最低收益目标 \(k\)，模型为：

\[
\begin{aligned}
\min\quad &t\\
\text{s.t.}\quad
&\sum_{i=1}^{n}x_i=M,\\
&\sum_{i=1}^{n}g_i x_i\geq k,\\
&t\geq q_i x_i,\qquad i=1,\ldots,n,\\
&x_i\geq0,\quad t\geq0.
\end{aligned}
\]

如果最低收益目标 \(k\) 设置过高，模型可能无可行解。求解后必须检查 `exitflag`，不能把失败结果当成投资方案。

### 模型三：风险—收益加权综合

可以将风险和收益合成为一个目标：

\[
\min\quad s\frac{t}{T}-(1-s)\frac{R(x)}{G},
\qquad 0\leq s\leq1.
\]

其中：

- \(s\) 是风险偏好权重；
- \(T>0\)、\(G>0\) 是风险和收益的尺度，用于统一量纲；
- \(s=0\) 时只考虑收益最大化；
- \(s=1\) 时只考虑风险最小化。

若已提前完成无量纲化，也可以简写为：

\[
\min\quad st-(1-s)R(x).

\]

但不能直接把金额、比例或不同量纲的指标机械相加。权重改变的是模型偏好，不自动等于真实投资者的风险概率或收益概率。

## 四、MATLAB `linprog` 求解框架

下面代码以模型一为例。变量向量取：

\[
z=\begin{bmatrix}x_1&\cdots&x_n\end{bmatrix}^{\mathsf T}.
\]

模型一是最大化问题，`linprog` 默认求最小化，因此目标系数使用 `-g`。

```matlab
% 输入数据
M = 100000;                         % 总投资金额
r = [0.08; 0.12; 0.05];             % 平均收益率
q = [0.10; 0.25; 0.03];             % 风险损失率
p = [0.01; 0.02; 0.005];            % 交易费率
a = 8000;                           % 风险损失金额上限

g = r - p;                           % 净收益率
n = numel(g);
assert(numel(q) == n && numel(p) == n, ...
    '收益率、风险率和费率长度必须一致');
assert(M >= 0 && a >= 0, ...
    '总资金和风险上限必须非负');

% max g' * x  <=>  min (-g)' * x
f = -g;

% 预算等式：sum(x) = M
Aeq = ones(1, n);
beq = M;

% 风险约束：q_i * x_i <= a
A = diag(q);
b = a * ones(n, 1);

lb = zeros(n, 1);
ub = [];

[x, fval, exitflag, output] = linprog( ...
    f, A, b, Aeq, beq, lb, ub);

if exitflag <= 0
    error('模型一求解失败：%s', output.message);
end

netReturn = g' * x;
riskLoss = max(q .* x);
fprintf('最大净收益：%.6f\n', netReturn);
fprintf('组合最大单项风险损失：%.6f\n', riskLoss);
fprintf('预算误差：%.3e\n', abs(sum(x) - M));
disp('各资产投资金额：');
disp(x);
```

## 五、模型二与模型三的 MATLAB 写法

### 1. 模型二：固定收益、最小化风险

变量向量改为：

\[
z=\begin{bmatrix}x_1&\cdots&x_n&t\end{bmatrix}^{\mathsf T}.
\]

```matlab
% g、q、M、n 已由前文定义，k 为最低净收益目标
k = 8000;

% min t
f = [zeros(n, 1); 1];

% 预算：sum(x) = M
Aeq = [ones(1, n), 0];
beq = M;

% 最低收益：g' * x >= k  ->  -g' * x <= -k
A_return = [-g', 0];
b_return = -k;

% 风险：q_i*x_i - t <= 0
A_risk = [diag(q), -ones(n, 1)];
b_risk = zeros(n, 1);

A = [A_return; A_risk];
b = [b_return; b_risk];
lb = zeros(n + 1, 1);
ub = [];

[z, fval, exitflag, output] = linprog( ...
    f, A, b, Aeq, beq, lb, ub);

if exitflag <= 0
    error('模型二求解失败：%s', output.message);
end

x = z(1:n);
t = z(end);
fprintf('达到最低收益：%.6f\n', g' * x);
fprintf('最小风险损失：%.6f\n', t);
```

### 2. 模型三：加权收益—风险目标

仍使用变量 \(z=[x;t]\)，风险约束保持不变。假设 `T` 和 `G` 是正的归一化尺度：

```matlab
s = 0.5;                 % 风险偏好权重
T = M;                   % 风险尺度示例，实际应按数据设定
G = M;                   % 收益尺度示例，实际应按数据设定
assert(T > 0 && G > 0 && s >= 0 && s <= 1, ...
    '权重和归一化尺度设置不合法');

% min s*t/T - (1-s)*(g'*x)/G
f = [-(1 - s) * g / G; s / T];

Aeq = [ones(1, n), 0];
beq = M;
A = [diag(q), -ones(n, 1)];
b = zeros(n, 1);
lb = zeros(n + 1, 1);
ub = [];

[z, fval, exitflag, output] = linprog( ...
    f, A, b, Aeq, beq, lb, ub);

if exitflag <= 0
    error('模型三求解失败：%s', output.message);
end

x = z(1:n);
t = z(end);
netReturn = g' * x;
fprintf('净收益：%.6f，风险损失：%.6f\n', netReturn, t);
```

## 六、风险—收益曲线扫描

为了观察不同风险偏好下的方案，可以扫描多个风险上限，分别求解模型一。每个风险上限对应一个最大收益点，连接这些点可以得到风险—收益权衡曲线的一部分。

```matlab
riskGrid = linspace(0.01 * M, 0.20 * M, 30).';
returnGrid = nan(size(riskGrid));
actualRisk = nan(size(riskGrid));

for k = 1:numel(riskGrid)
    a = riskGrid(k);
    A = diag(q);
    b = a * ones(n, 1);

    [xk, fval, exitflag] = linprog( ...
        -g, A, b, ones(1, n), M, zeros(n, 1), []);

    if exitflag > 0
        returnGrid(k) = g' * xk;
        actualRisk(k) = max(q .* xk);
    end
end

valid = isfinite(returnGrid);
plot(actualRisk(valid), returnGrid(valid), 'o-', 'LineWidth', 1.5);
xlabel('最大单项风险损失');
ylabel('最大净收益');
```

扫描结果不是完整的金融有效前沿定义，而是当前风险指标、收益指标和参数范围下的离散近似。若要得到更严格的有效前沿，还需明确风险度量、约束条件和参数扫描范围。

## 七、结果检查清单

每个模型求解后至少检查：

1. `exitflag` 是否表示成功；
2. 预算约束 `sum(x) = M` 是否满足；
3. 投资金额是否非负；
4. 模型一的每个风险约束 `q(i)*x(i) <= a` 是否满足；
5. 模型二的收益是否达到最低目标 `k`；
6. 辅助变量 `t` 是否满足 `t >= q(i)*x(i)`，并且与实际最大风险一致；
7. 净收益是否按 `g' * x` 正确计算；
8. 改变风险上限、收益目标或权重后，是否重新比较方案和目标值。

## 八、知识总结

投资收益与风险问题的建模流程为：

```text
确定资产收益率、风险率、交易费率和总资金
→ 定义投资金额 x_i 与预算约束
→ 明确收益指标和风险指标
→ 用辅助变量 t 线性化最大风险
→ 选择约束法或加权法处理多目标
→ 调用 linprog 求解
→ 扫描风险上限或权重
→ 比较风险、收益和投资方案
→ 检查可行性与结果解释
```

本节的核心不是追求一个固定的“最优投资组合”，而是学习如何把收益—风险的多目标问题转化为一组可计算的线性规划，并通过参数扫描观察方案之间的权衡关系。
