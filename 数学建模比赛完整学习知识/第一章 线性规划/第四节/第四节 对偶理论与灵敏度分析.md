# 第四节 对偶理论与灵敏度分析

## 一、对偶问题的基本思想

每个线性规划问题通常都有一个与之对应的对偶问题。原问题和对偶问题不是两个互不相关的问题，而是同一个资源配置问题的两种描述方式。

以生产计划为例：

- **原问题**：决定生产多少，使总利润最大；
- **对偶问题**：给各种资源定价，使资源总估值最小，同时保证每种产品的资源价值不低于其利润。

原问题中的约束通常代表资源限制，对偶问题中的变量则可以解释为对应资源的**影子价格**。影子价格描述资源供给量增加一个单位时，最优目标值在局部范围内的改善价值。

## 二、原问题与对偶问题

考虑如下标准形式的原问题（P）：

\[
\begin{aligned}
\max\quad &c^{\mathsf T}x\\
\text{s.t.}\quad &Ax\leq b,\\
&x\geq0,
\end{aligned}
\]

其中 \(A\in\mathbb{R}^{m\times n}\)，\(x\in\mathbb{R}^n\)，\(b\in\mathbb{R}^m\)，\(c\in\mathbb{R}^n\)。

其对偶问题（D）为：

\[
\begin{aligned}
\min\quad &b^{\mathsf T}y\\
\text{s.t.}\quad &A^{\mathsf T}y\geq c,\\
&y\geq0.
\end{aligned}
\]

对应关系如下：

| 原问题 | 对偶问题 |
|---|---|
| \(m\) 个约束 | \(m\) 个对偶变量 |
| \(n\) 个变量 | \(n\) 个对偶约束 |
| 目标系数 \(c\) | 约束右端项 \(c\) |
| 约束右端项 \(b\) | 目标系数 \(b\) |
| 最大化 | 最小化 |
| \(Ax\leq b\) | \(A^{\mathsf T}y\geq c\) |

原问题的约束矩阵转置后出现在对偶问题中，原问题的目标系数和右端项在对偶中交换位置。

> 其他约束方向或变量符号会产生不同的对偶符号规则。本节先掌握上述“最大化、\(\leq\) 约束、非负变量”的标准情形；遇到混合形式时，应先统一形式或逐条应用对偶规则，不能机械套用本式。

## 三、对偶理论的基本性质

### 1. 弱对偶性

若 \(x\) 是原问题的任意可行解，\(y\) 是对偶问题的任意可行解，则：

\[
c^{\mathsf T}x\leq b^{\mathsf T}y.
\]

证明的核心是：由 \(A^{\mathsf T}y\geq c\)、\(x\geq0\) 得：

\[
c^{\mathsf T}x\leq y^{\mathsf T}Ax,
\]

再由 \(Ax\leq b\)、\(y\geq0\) 得：

\[
y^{\mathsf T}Ax\leq y^{\mathsf T}b=b^{\mathsf T}y.
\]

因此，原问题任意可行解的目标值都不超过对偶问题任意可行解的目标值。它可以用于检验一个候选解是否可能达到最优。

### 2. 强对偶性

在满足线性规划最优解存在等适当条件时，原问题和对偶问题的最优目标值相等：

\[
\max c^{\mathsf T}x=\min b^{\mathsf T}y.
\]

因此，如果找到一对原、对偶可行解 \(x^*\)、\(y^*\)，并且满足：

\[
c^{\mathsf T}x^*=b^{\mathsf T}y^*,
\]

则这两个解分别都是原问题和对偶问题的最优解。这是“可行性 + 目标值相等”的最优性证书。

### 3. 可行性与无界性的关系

弱对偶性还给出一些诊断信息：

- 若原问题存在可行解，而对偶问题无可行解，则原问题可能无界；
- 若对偶问题存在可行解，则原问题的最大值不可能超过某个有限的对偶目标值；
- 原问题和对偶问题都可能不可行，具体情况要结合求解器状态判断。

不能仅凭一个问题的 `exitflag` 或某个变量值，跳过可行性和目标值检查。

## 四、互补松弛性

互补松弛性把原问题的资源使用情况与对偶变量的影子价格联系起来。对原、对偶可行解 \(x\)、\(y\)，若它们满足最优性条件，则有：

\[
y_i\left(b_i-(Ax)_i\right)=0,
\qquad i=1,\ldots,m,
\]

以及：

\[
x_j\left((A^{\mathsf T}y)_j-c_j\right)=0,
\qquad j=1,\ldots,n.
\]

它们分别表示：

- 若原问题第 \(i\) 个资源约束有松弛量，即 \((Ax)_i<b_i\)，则对应对偶变量 \(y_i=0\)；
- 若对偶变量 \(y_i>0\)，则原问题第 \(i\) 个资源约束必须是紧约束（binding），即 \((Ax)_i=b_i\)；
- 若原变量 \(x_j>0\)，则对应对偶约束必须取等式，即 \((A^{\mathsf T}y)_j=c_j\)；
- 若对偶约束有严格剩余，即 \((A^{\mathsf T}y)_j>c_j\)，则对应原变量 \(x_j=0\)。

其中，`binding` 表示约束恰好达到边界。互补松弛性常用于：

1. 根据已知的原问题最优解推断对偶变量的零值；
2. 根据已知的对偶最优解判断哪些原变量可能为正；
3. 检查一对候选原、对偶解是否满足最优性条件；
4. 解释哪些资源稀缺、哪些资源存在剩余。

教材简化例中给出的数值（如某组 \(y^*\) 和 \(x^*\)）必须结合完整的 \(A,b,c\) 和约束方向才能复核。本节不把缺少完整模型的数值对作为独立结论；实际使用时应代入上述两组互补关系逐项检查。

## 五、MATLAB 中分别求解原问题与对偶问题

对标准原问题：

\[
\max c^{\mathsf T}x,\quad Ax\leq b,\quad x\geq0,
\]

MATLAB 的 `linprog` 默认求最小化，因此原问题目标系数使用 `-c`。对偶问题直接是最小化问题，但约束 \(A^{\mathsf T}y\geq c\) 需要改写为：

\[
-A^{\mathsf T}y\leq-c.
\]

```matlab
% 标准原问题：max c' * x, s.t. A*x <= b, x >= 0
A = [2 1; 1 1; 0 1];
b = [10; 8; 7];
c = [4; 3];

% 原问题：linprog 默认最小化，所以取 -c
[x, fvalP, exitflagP, outputP, lambdaP] = linprog( ...
    -c, A, b, [], [], zeros(size(c)), []);

if exitflagP <= 0
    error('原问题求解失败：%s', outputP.message);
end
zP = -fvalP;

% 对偶问题：min b' * y, s.t. A' * y >= c, y >= 0
% 改写为 -A' * y <= -c
[y, fvalD, exitflagD, outputD] = linprog( ...
    b, -A', -c, [], [], zeros(size(b)), []);

if exitflagD <= 0
    error('对偶问题求解失败：%s', outputD.message);
end
zD = fvalD;

fprintf('原问题最优值：%.8f\n', zP);
fprintf('对偶问题最优值：%.8f\n', zD);
fprintf('原对偶目标值差：%.3e\n', abs(zP - zD));

% 互补松弛性检查
primalSlack = b - A * x;
dualSlack = A' * y - c;
fprintf('原约束松弛量最大误差：%.3e\n', ...
    max(abs(y .* primalSlack)));
fprintf('对偶约束松弛量最大误差：%.3e\n', ...
    max(abs(x .* dualSlack)));
```

若 `zP` 与 `zD` 在数值容差内相等，且两组互补乘积接近 0，则原、对偶解的最优性得到数值验证。

## 六、灵敏度分析

灵敏度分析研究模型系数发生变化时，最优解和最优目标值如何变化。常见变化包括：

- 右端项 \(b_i\) 变化：资源供给量、容量或需求量变化；
- 目标系数 \(c_j\) 变化：利润、成本或收益变化；
- 约束系数 \(a_{ij}\) 变化：单位产品资源消耗或技术参数变化。

### 1. 影子价格

在适用的局部变化范围内，对偶最优变量 \(y_i^*\) 可以解释为第 \(i\) 个资源约束右端项变化一个单位时，原问题最优目标值的边际变化率：

\[
\Delta z^*\approx y_i^*\Delta b_i.
\]

这不是任意大范围变化下的精确公式。超过当前最优基的允许范围后，最优基可能改变，影子价格也可能随之改变，需要重新求解。

### 2. 目标系数变化

当某个产品的利润或成本发生变化时，需要判断当前基是否仍然最优。若变化超过允许范围，原最优生产方案可能发生改变。实际建模中可以：

1. 先记录基准模型的最优解和最优值；
2. 改变目标系数并重新调用 `linprog`；
3. 比较新旧方案、目标值、约束松弛量和资源利用率；
4. 记录最优方案发生切换的临界参数区间。

### 3. 参数线性规划

若把某个参数记为 \(\theta\)，并令右端项、目标系数或约束系数依赖于 \(\theta\)，就得到参数线性规划。参数变化时，最优解通常在若干临界点发生分段变化。

本节只掌握概念和分析流程；对于具体的允许增减范围、最优基变化和临界点，应结合 MATLAB 求解器输出或逐参数重求解进行验证，不能仅凭影子价格外推到任意范围。

## 七、结果检查清单

求解原、对偶问题后至少检查：

1. 原问题和对偶问题的 `exitflag` 是否表示成功；
2. 原解是否满足 `A*x <= b` 和 `x >= 0`；
3. 对偶解是否满足 `A'*y >= c` 和 `y >= 0`；
4. 原、对偶最优目标值是否在数值容差内相等；
5. `y .* (b - A*x)` 是否接近 0；
6. `x .* (A'*y - c)` 是否接近 0；
7. 参数变化后，是否重新检查可行性、目标值和最优方案。

## 八、知识总结

对偶理论的学习主线为：

```text
写出原问题
→ 按目标方向、约束方向和变量符号构造对偶问题
→ 分别检查原、对偶可行性
→ 用弱对偶性理解目标值界
→ 用强对偶性验证最优目标值相等
→ 用互补松弛性解释资源和变量状态
→ 用影子价格分析小范围参数变化
→ 超出允许范围后重新求解并比较方案
```

对偶问题提供了原问题的另一种资源定价视角；强对偶性给出最优值相等关系；互补松弛性连接资源剩余与影子价格，是从求解结果解释模型的重要工具。灵敏度分析则进一步回答“数据发生变化后，原方案还能否继续使用”。
