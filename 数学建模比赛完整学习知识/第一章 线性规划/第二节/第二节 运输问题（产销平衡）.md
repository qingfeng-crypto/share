# 第二节 运输问题（产销平衡）

## 一、问题概念

运输问题研究如何把若干个产地的商品运往若干个销地，在满足各产地供给量和各销地需求量的条件下，使总运输费用最小。

运输问题的基本数据包括：

- 产地数量：\(m\) 个；
- 销地数量：\(n\) 个；
- 产地 \(i\) 的供给量：\(a_i\)；
- 销地 \(j\) 的需求量：\(b_j\)；
- 从产地 \(i\) 运往销地 \(j\) 的单位运输费用：\(c_{ij}\)。

本节讨论**产销平衡运输问题**，即总供给量等于总需求量：

\[
\sum_{i=1}^{m}a_i=\sum_{j=1}^{n}b_j.
\]

## 二、决策变量

设：

\[
x_{ij}
\]

表示从产地 \(i\) 运往销地 \(j\) 的商品数量，其中：

\[
i=1,2,\ldots,m,\qquad j=1,2,\ldots,n.
\]

每个 \(x_{ij}\) 都是非负变量：

\[
x_{ij}\geq0.
\]

如果商品必须按整数件运输，还需要增加整数约束；当商品数量可以按吨、箱等连续计量时，可按连续变量处理。

## 三、目标函数

从产地 \(i\) 向销地 \(j\) 运输 \(x_{ij}\) 单位商品产生的运输费用为：

\[
c_{ij}x_{ij}.
\]

所有运输路线的总费用为：

\[
\sum_{i=1}^{m}\sum_{j=1}^{n}c_{ij}x_{ij}.
\]

运输问题的目标是使总运输费用最小：

\[
\min\quad \sum_{i=1}^{m}\sum_{j=1}^{n}c_{ij}x_{ij}.
\]

## 四、约束条件

### 1. 产地供给约束

每个产地发出的商品总量必须等于该产地的供给量：

\[
\sum_{j=1}^{n}x_{ij}=a_i,
\qquad i=1,2,\ldots,m.
\]

### 2. 销地需求约束

每个销地收到的商品总量必须等于该销地的需求量：

\[
\sum_{i=1}^{m}x_{ij}=b_j,
\qquad j=1,2,\ldots,n.
\]

### 3. 非负约束

\[
x_{ij}\geq0,
\qquad i=1,\ldots,m,\quad j=1,\ldots,n.
\]

## 五、产销平衡运输模型

完整数学模型为：

\[
\begin{aligned}
\min\quad &\sum_{i=1}^{m}\sum_{j=1}^{n}c_{ij}x_{ij}\\
\text{s.t.}\quad
&\sum_{j=1}^{n}x_{ij}=a_i,\qquad i=1,2,\ldots,m,\\
&\sum_{i=1}^{m}x_{ij}=b_j,\qquad j=1,2,\ldots,n,\\
&x_{ij}\geq0.
\end{aligned}
\]

目标函数和约束条件都是线性的，因此产销平衡运输问题是线性规划问题，可以使用线性规划算法求解。

## 六、产销平衡关系与约束冗余

将所有销地需求约束相加，有：

\[
\sum_{j=1}^{n}\sum_{i=1}^{m}x_{ij}
=\sum_{j=1}^{n}b_j.
\]

将所有产地供给约束相加，有：

\[
\sum_{i=1}^{m}\sum_{j=1}^{n}x_{ij}
=\sum_{i=1}^{m}a_i.
\]

当满足：

\[
\sum_{i=1}^{m}a_i=\sum_{j=1}^{n}b_j,
\]

两组约束的总和相同。因此，供给约束与需求约束中至少有一条约束可以由其余约束和产销平衡条件推出，约束系数矩阵存在结构上的相关性。

这并不表示供给约束或需求约束可以随意删除。使用通用线性规划求解器时，可以保留完整的约束；如果需要消除线性相关性，可以删除一条供给或需求等式约束，但必须保证模型的可行解集合不变。

## 七、运输表表示法

运输问题通常用运输表组织数据：

|  | 销地 1 | 销地 2 | \(\cdots\) | 销地 \(n\) | 供给量 |
|---|---:|---:|---:|---:|---:|
| 产地 1 | \(c_{11}\) | \(c_{12}\) | \(\cdots\) | \(c_{1n}\) | \(a_1\) |
| 产地 2 | \(c_{21}\) | \(c_{22}\) | \(\cdots\) | \(c_{2n}\) | \(a_2\) |
| \(\vdots\) | \(\vdots\) | \(\vdots\) |  | \(\vdots\) | \(\vdots\) |
| 产地 \(m\) | \(c_{m1}\) | \(c_{m2}\) | \(\cdots\) | \(c_{mn}\) | \(a_m\) |
| 需求量 | \(b_1\) | \(b_2\) | \(\cdots\) | \(b_n\) | |

表中每个单位费用 \(c_{ij}\) 对应一个运输路线变量 \(x_{ij}\)。求解结果可以填回同样的运输表，形成各路线的最优调运量。

## 八、表上作业法

产销平衡运输问题的约束矩阵具有特殊结构，因此除了直接使用线性规划算法，还可以使用针对运输表设计的专门方法，通常称为**表上作业法**。

表上作业法的基本特点是：

- 直接在运输表上记录各路线的费用和调运量；
- 利用供给约束和需求约束维护运输方案的可行性；
- 利用运输问题的特殊结构减少通用单纯形法的计算量；
- 适用于产销平衡运输问题的专门求解。

在实际编程中，可以使用通用 `linprog` 求解器验证表上作业法得到的结果；两者应得到相同的最优总运输费用和等价的最优运输方案。

## 九、MATLAB 矩阵表达

将 \(m\times n\) 个运输变量按行展开为列向量：

\[
x=\begin{bmatrix}
x_{11}&x_{12}&\cdots&x_{1n}&x_{21}&\cdots&x_{mn}
\end{bmatrix}^{\mathsf T}.
\]

目标函数系数向量为运输费用矩阵按行展开后的列向量：

\[
f=\operatorname{vec}_{\mathrm{row}}(C)^{\mathsf T}.
\]

由于运输问题是最小化问题，直接将运输费用作为 `f` 传给 `linprog`。

供给约束矩阵由每个产地对应的一组变量组成，需求约束矩阵由每个销地对应的变量组成。使用 MATLAB 时可直接构造等式约束：

\[
A_{\mathrm{eq}}x=b_{\mathrm{eq}}.
\]

其中：

\[
b_{\mathrm{eq}}=
\begin{bmatrix}
a_1&\cdots&a_m&b_1&\cdots&b_n
\end{bmatrix}^{\mathsf T}.
\]

所有运输变量的下界均为 0：

\[
lb=0.
\]

## 十、MATLAB R2024b 求解框架

下面的框架适用于已经给定运输费用矩阵 `C`、供给向量 `supply` 和需求向量 `demand` 的产销平衡运输问题：

```matlab
% C(i,j)：产地 i 到销地 j 的单位运输费用
% supply(i)：产地 i 的供给量
% demand(j)：销地 j 的需求量
[m, n] = size(C);

assert(numel(supply) == m, '供给向量长度与产地数量不一致');
assert(numel(demand) == n, '需求向量长度与销地数量不一致');
assert(abs(sum(supply) - sum(demand)) <= 1e-10, ...
    '该模型要求总供给量等于总需求量');

f = C(:);

% C(:) 按列展开：先列出销地 1 的所有产地，再列出销地 2 的所有产地
% 产地供给等式：每一行对应一个产地
A_supply = kron(ones(1, n), eye(m));

% 销地需求等式：每一行对应一个销地
A_demand = kron(eye(n), ones(1, m));

Aeq = [A_supply; A_demand];
beq = [supply(:); demand(:)];

lb = zeros(m * n, 1);
ub = [];

[x, fval, exitflag, output] = linprog( ...
    f, [], [], Aeq, beq, lb, ub);

if exitflag <= 0
    error('运输问题求解失败：%s', output.message);
end

transportPlan = reshape(x, n, m).';
totalCost = fval;

% 结果核验
assert(max(abs(sum(transportPlan, 2) - supply(:))) <= 1e-7, ...
    '产地供给约束未满足');
assert(max(abs(sum(transportPlan, 1).' - demand(:))) <= 1e-7, ...
    '销地需求约束未满足');
assert(min(transportPlan(:)) >= -1e-9, ...
    '出现负运输量');

disp('最优运输方案：');
disp(transportPlan);
fprintf('最小总运输费用：%.6f\n', totalCost);
```

这里使用：

```matlab
f = C(:);
```

是因为 MATLAB 按列展开矩阵，而 `A_supply` 和 `A_demand` 的构造也必须与这种变量排列方式保持一致。若改变变量展开顺序，目标系数向量和约束矩阵必须同步改变。

## 十一、结果检查

得到运输方案后，至少检查以下内容：

1. 每个产地发出的总量是否等于供给量；
2. 每个销地收到的总量是否等于需求量；
3. 所有运输量是否非负；
4. 总运输费用是否等于 \(\sum_i\sum_j c_{ij}x_{ij}\)；
5. 若使用表上作业法，是否与 `linprog` 得到相同的最优值。

## 十二、知识总结

产销平衡运输问题的建模流程为：

```text
整理产地供给、销地需求和单位运费
→ 检查总供给量是否等于总需求量
→ 定义路线运输量 x_ij
→ 建立产地供给等式
→ 建立销地需求等式
→ 建立总运输费用最小化目标
→ 使用运输表或线性规划算法求解
→ 检查供给、需求、非负性和总费用
```
