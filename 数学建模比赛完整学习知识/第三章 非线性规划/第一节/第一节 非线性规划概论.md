# 第一节 非线性规划概论

## 一、问题背景

非线性规划（Nonlinear Programming，NLP）是运筹学的重要分支，其目标函数或约束条件中包含非线性函数。在实际问题中，如投资决策、工程设计、经济调度等，往往无法用线性关系描述，因此非线性规划具有广泛的应用价值。

## 二、实例与定义

### 2.1 投资决策问题（例1）

某企业有 n 个项目可供选择投资，至少要对其中一个项目投资。企业拥有总资金 A 元，投资第 i 个项目需资金 a_i 元，预计收益 b_i 元。试选择最佳投资方案。

设决策变量 x_i ∈ {0,1} 表示是否投资第 i 个项目，则该问题的数学模型为：

```
max Q = (∑b_i x_i) / (∑a_i x_i)
```

约束条件：0 < ∑a_i x_i ≤ A，x_i(1-x_i)=0，i=1,…,n。

该模型中目标函数为分式，约束含整数条件，属于非线性规划。

### 2.2 非线性规划的一般形式

非线性规划的一般形式（NP问题）可表述为：

```
min f(x)
s.t. h_j(x) ≤ 0, j=1,…,q
g_i(x)=0, i=1,…,p
```

其中 x 为决策变量，f 为目标函数，g_i 为等式约束，h_j 为不等式约束。

## 三、线性规划与非线性规划的区别

线性规划的最优解只能在可行域的边界（顶点）上达到；而非线性规划的最优解可能在可行域内的任意点。

线性规划使用单纯形法求解；非线性规划需根据函数性质选用梯度法、牛顿法、罚函数法等不同方法。

非线性规划的求解难度更大，通常只能得到局部最优解，而非全局最优解。

## 四、Matlab 解法：fmincon 函数

### 4.1 fmincon 基本用法

Matlab 中求解非线性规划的核心函数为 fmincon，其基本调用格式为：

```matlab
[x,fval] = fmincon(fun,x0,A,b,Aeq,beq,LB,UB,nonlcon,options)
```
其中 fun 为目标函数 M 文件，x0 为初始点，A,b,Aeq,beq 为线性约束，LB,UB 为变量上下界，nonlcon 为非线性约束 M 文件。

### 4.2 例2：fmincon 求解示例

求解非线性规划：

```
min f(x)=x₁²+x₂²+x₃²+8
```

约束：x₁²-x₂+x₃² ≥ 0；x₁+x₂²+x₃³ ≤ 20；-x₁-x₂²+2=0；x₂+2x₃²=3；x₁,x₂,x₃ ≥ 0

求解步骤：

**（1）编写 fun1.m 定义目标函数：**

```matlab
function f=fun1(x); f=sum(x.^2)+8;
```
**（2）编写 fun2.m 定义非线性约束：**

```matlab
function [g,h]=fun2(x);
g=[-x(1)^2+x(2)-x(3)^2; x(1)+x(2)^2+x(3)^3-20];
h=[-x(1)-x(2)^2+2; x(2)+2*x(3)^2-3];
```
**（3）主程序调用：**

```matlab
options=optimset('largescale','off');
[x,y]=fmincon('fun1',rand(3,1),[],[],[],[],zeros(3,1),[],'fun2',options)
```
结果：x₁=0.5522, x₂=1.2033, x₃=0.9478，最小值 y=10.6511。

## 五、基本迭代格式

非线性规划的求解一般采用迭代法，其基本格式为：

```
x^(k+1) = x^k + t_k · p^k
```

其中 x^k 为第 k 轮迭代点，p^k 为搜索方向，t_k 为步长。核心问题是如何选择搜索方向和步长，不同的选择方法对应不同的算法。

## 六、凸规划

当目标函数 f(x) 为凸函数、可行域为凸集时，该非线性规划称为凸规划。凸规划具有重要性质：局部最优解就是全局最优解，且 KKT 条件是最优解的充要条件。

## 七、小结

本节介绍了非线性规划的基本概念、与线性规划的区别、fmincon 函数的使用方法以及基本迭代格式。通过例1（投资决策）和例2（fmincon 求解），初步掌握了非线性规划的建模与求解流程。后续将深入学习无约束问题的各种求解算法。
