# 第三节 约束极值问题

## 一、问题背景

约束极值问题（规划问题）是实际中更常见的一类优化问题，其数学模型包含等式和不等式约束。求解约束极值问题的难度远大于无约束问题，常用的思路包括：将约束问题转化为无约束问题（如罚函数法），或将非线性规划转化为线性规划。

## 二、二次规划

### 2.1 数学模型

当目标函数为二次函数、约束条件全为线性时，称为二次规划（Quadratic Programming）。Matlab 中二次规划的标准形式为：

```
min (1/2)x^T H x + f^T x
```

约束：Ax ≤ b，Aeq·x = beq。其中 H 为实对称矩阵，f 为列向量。

### 2.2 quadprog 函数用法

```matlab
[x,fval] = quadprog(H,f,A,b,Aeq,beq,LB,UB,x0,options)
```
返回值 x 为决策向量，fval 为目标函数值。

### 2.3 例8：二次规划求解

问题：求解二次规划

```
min f(x)=2x₁²-4x₁x₂+4x₂²-6x₁-3x₂
```

约束：x₁+x₂≤3；4x₁+x₂≤9；x₁,x₂≥0

Matlab 求解代码：

```matlab
h=[4,-4;-4,8];
f=[-6;-3];
a=[1,1;4,1];
b=[3;9];
[x,value]=quadprog(h,f,a,b,[],[],zeros(2,1))
```
结果：x₁=1.9500，x₂=1.0500，最小值 f(x)=-11.0250。

## 三、罚函数法（SUMT）

### 3.1 基本原理

罚函数法（外罚函数法）是序列无约束最小化技术（Sequential Unconstrained Minimization Technique，SUMT）的核心方法。其基本思想是：利用约束函数构造"罚函数"，将其加到原目标函数上，构成增广目标函数，从而将约束问题转化为无约束问题。

考虑一般约束问题：

```
min f(x)
s.t. g_i(x)≤0, i=1,…,r; h_j(x)≥0, j=1,…,s; k_m(x)=0, m=1,…,t
```

构造增广目标函数：

```
P(x,M) = f(x) + M·∑max(g_i(x),0) - M·∑min(h_j(x),0) + M·∑|k_m(x)|
```

```
其中 M>0 为充分大的罚因子。当约束被违反时，惩罚项 M 乘以正数使目标函数增大，迫使解向可行域靠拢。当 M 足够大时，无约束问题的最优解就是原约束问题的最优解。
```

### 3.2 算法步骤

**Step 1：选取充分大的罚因子 M（如 M=50000）。**

**Step 2：构造增广目标函数（罚函数）P(x,M) 的 M 文件。**

**Step 3：使用无约束极小化命令（如 fminunc）求解 min P(x,M)。**

**Step 4：所得最优解 x 即为原约束问题的最优解。**

## 四、Matlab 其他约束优化函数

### 4.1 fminbnd（单变量区间优化）

```matlab
[x,fval] = fminbnd(fun,x1,x2)
```
求单变量函数在区间 [x₁,x₂] 上的极小值。例10：求 f(x)=(x-3)²-1 在 [0,5] 上的最小值。

### 4.2 fseminf（半无穷约束）

```
x = fseminf(fun,x0,ntheta,seminfcon,A,b,Aeq,beq)
```

处理含有半无穷约束（如对连续参数 w 的无限个约束）的优化问题。

### 4.3 fminimax（极大极小问题）

```
x = fminimax(fun,x0,A,b,Aeq,beq,LB,UB,nonlcon)
```

求解 min_x{max_i F_i(x)} 形式的极大极小问题。

### 4.4 optimtool 图形界面

在 Matlab 命令窗口输入 optimtool 可打开优化工具箱的图形用户界面，通过填写参数、选择算法即可求解各类优化问题，适合初学者快速上手。

## 五、小结

本节介绍了约束极值问题的两类重要方法——二次规划（quadprog）和罚函数法（SUMT）。二次规划适用于目标函数为二次、约束为线性的特殊情况；罚函数法则更具通用性，通过将约束问题转化为无约束问题来求解。同时介绍了 Matlab 优化工具箱中的多种约束优化函数，在实际应用中应根据问题特点灵活选择。
