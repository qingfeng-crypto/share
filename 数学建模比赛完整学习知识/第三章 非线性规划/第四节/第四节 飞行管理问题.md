# 第四节 飞行管理问题

## 一、问题背景

飞行管理问题是一个经典的非线性规划应用案例。在约 10,000m 高空、边长 160km 的正方形区域内，若干架飞机作水平飞行。当一架新飞机到达区域边缘时，需判断是否会与区域内飞机碰撞，若会，则需调整各架飞机的飞行方向角以避免碰撞。

## 二、基本假设与数据

问题假设如下：

不碰撞标准：任意两架飞机距离大于 8km

方向角调整幅度不超过 30°

所有飞机飞行速度均为 800 km/h

```
新进入飞机与区域内飞机初始距离≥60km
```

最多考虑 6 架飞机

不考虑飞机离开区域后的状况

## 三、符号说明

(x_i⁰, y_i⁰)：第 i 架飞机的初始位置

```
θ_i⁰：第 i 架飞机的原飞行方向角
```

```
Δθ_i：第 i 架飞机的方向角调整量（|Δθ_i|≤π/6）
```

```
θ_i = θ_i⁰ + Δθ_i：调整后的飞行方向角
```

(x_i(t), y_i(t)) = (x_i⁰+at·cosθ_i, y_i⁰+at·sinθ_i)：t 时刻位置

## 四、飞机不碰撞条件

### 4.1 模型一：基于相对运动

将飞机 i 视为不动，飞机 j 以相对速度 v_ij 运动。当相对飞行方向角 β_ij 与两机初始连线夹角满足一定条件时，两机不会碰撞。

两架飞机不碰撞的条件为：

|β_ij⁰ + (Δθ_i+Δθ_j)/2| > α_ij⁰

```
其中 α_ij⁰ = arcsin(8 / r_ij(0))，r_ij(0) 为两机初始距离。
```

### 4.2 模型二：基于距离平方

两架飞机 i,j 不发生碰撞的条件等价于距离平方始终大于 64：

(x_i(t)-x_j(t))² + (y_i(t)-y_j(t))² > 64

```
记 l_ij(t)=ã(i,j)t²+ b̃(i,j)t+ c̃(i,j)-64，则两机不碰撞的条件为判别式：
```

```
Δ(i,j) = b̃² - 4ã·c̃ < 0
```

其中：

```
ã(i,j)=4a²·sin²[(θ_i-θ_j)/2]
```

```
b̃(i,j)=2a[(x_i⁰-x_j⁰)(cosθ_i-cosθ_j)+(y_i⁰-y_j⁰)(sinθ_i-sinθ_j)]
```

```
c̃(i,j)=(x_i⁰-x_j⁰)²+(y_i⁰-y_j⁰)²-64
```

## 五、非线性规划模型

### 5.1 模型一（调整量绝对值之和最小）

```
min ∑|Δθ_i|
```

约束：|β_ij⁰+(Δθ_i+Δθ_j)/2| > α_ij⁰（i≠j），|Δθ_i|≤30°

该模型可用 LINGO 求解，求得 Δθ₃≈2.84°，Δθ₆≈0.79°，其余为 0。

### 5.2 模型二（调整量平方和最小）

```
min ∑(Δθ_i)²
```

约束：Δ(i,j)<0（1≤i≤5, i+1≤j≤6），|Δθ_i|≤π/6（i=1,…,6）

该模型为非线性规划，可用 Matlab 的 fmincon 或罚函数法求解（详见习题三第4、5题）。

## 六、小结

飞行管理问题是一个典型的非线性规划建模案例，体现了将实际工程问题转化为数学优化模型的全过程。核心是建立飞机不碰撞条件的数学表达，再根据实际需求（调整幅度最小）构造目标函数，最终形成可求解的非线性规划模型。该问题也可用相对运动或距离平方两种思路建立约束条件，分别得到不同的模型形式。
