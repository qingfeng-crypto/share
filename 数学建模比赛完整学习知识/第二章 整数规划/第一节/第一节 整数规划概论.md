# 第一节 整数规划概论

## 一、什么是整数规划

整数规划（Integer Programming，IP）是指部分或全部决策变量被限制为整数的最优化问题。

如果目标函数和约束条件都是线性的，则称为**整数线性规划**（Integer Linear Programming，ILP）。整数线性规划是数学建模和运筹优化中最常见、最成熟的一类整数规划问题。

一般形式可以写为：

\[
\begin{aligned}
\min\quad &c^{\mathsf T}x\\
\text{s.t.}\quad &Ax\leq b,\\
&x\geq0,\\
&x_j\in\mathbb{Z},\qquad j\in\mathcal{I},
\end{aligned}
\]

其中 \(\mathcal{I}\) 表示需要取整数的变量下标集合。未被 \(\mathcal{I}\) 包含的变量可以取实数。

## 二、整数规划的分类

### 1. 纯整数规划

所有决策变量都必须取整数：

\[
x_j\in\mathbb{Z},
\qquad j=1,\ldots,n.
\]

### 2. 混合整数规划

只有部分变量限制为整数，其余变量可以取连续值。例如：

- 车辆是否启用使用 0-1 变量；
- 运输量使用连续变量；
- 设备数量使用整数变量；
- 产品配比使用连续变量。

混合整数线性规划（MILP）在生产计划、设施选址、车辆路径、排班和投资组合中非常常见。

### 3. 0-1 整数规划

如果变量只能取 0 或 1，则称为 0-1 整数规划：

\[
x_j\in\{0,1\}.
\]

0-1 变量常用于表示“是否选择”“是否启用”“是否分配”和“是否连接”等逻辑决策。

## 三、线性规划松弛与整数规划的关系

去掉整数约束，只保留连续变量约束，可以得到整数规划的**线性规划松弛**（LP relaxation）。

对于最小化问题：

\[
z^*_{\mathrm{LP}}\leq z^*_{\mathrm{IP}};
\]

对于最大化问题：

\[
z^*_{\mathrm{LP}}\geq z^*_{\mathrm{IP}}.
\]

原因是：线性规划松弛的可行域包含整数规划的可行域，因此最小化时松弛问题可能取得更小的目标值，最大化时可能取得更大的目标值。

### 三种基本情况

#### 情况一：线性规划最优解恰好为整数

如果 LP 松弛最优解的所有整数变量都已经是整数，则它同时也是整数规划最优解，不需要继续分支。

某些具有特殊结构的模型还具有整数性，例如标准指派问题的约束矩阵具有全单位模性质，线性规划松弛能够得到整数最优解。

#### 情况二：整数规划无可行解

考虑：

\[
\begin{aligned}
\min\quad &x_1+x_2\\
\text{s.t.}\quad &2x_1+4x_2=5,\\
&x_1,x_2\geq0,\\
&x_1,x_2\in\mathbb{Z}.
\end{aligned}
\]

左端对整数 \(x_1,x_2\) 必为偶数，不可能等于 5，因此整数规划无可行解。

去掉整数约束后，连续问题有可行解，例如：

\[
x_1=0,\qquad x_2=1.25.
\]

这说明：

> 线性规划有可行解，不代表加入整数约束后仍有整数可行解。

#### 情况三：有整数可行解，但最优值变差

考虑：

\[
\begin{aligned}
\min\quad &x_1+x_2\\
\text{s.t.}\quad &2x_1+4x_2=6,\\
&x_1,x_2\geq0,\\
&x_1,x_2\in\mathbb{Z}.
\end{aligned}
\]

连续松弛问题的最优解为：

\[
x_1=0,\qquad x_2=1.5,
\qquad z^*_{\mathrm{LP}}=1.5.
\]

整数可行解包括 \((x_1,x_2)=(1,1)\) 和 \((3,0)\)，其中：

\[
z(1,1)=2,
\qquad z(3,0)=3.
\]

因此整数规划最优解为 \((1,1)\)，最优值为：

\[
z^*_{\mathrm{IP}}=2>1.5=z^*_{\mathrm{LP}}.
\]

这说明整数约束可能使最优目标值变差。

## 四、不能对连续解直接取整

对 LP 松弛最优解进行四舍五入、向上取整或向下取整，可能产生三类问题：

1. 取整后违反等式约束；
2. 取整后违反容量、资源等不等式约束；
3. 取整后虽然可行，但不一定是整数规划最优解。

因此：

> 连续最优解可以作为整数规划求解的参考、界或启发式起点，但不能把简单取整结果直接当作整数规划最优解。

## 五、整数规划的主要求解方法

不同整数规划类型需要使用不同方法，不能把某一种算法视为所有整数规划的通用解法。

| 方法 | 主要适用问题 | 能否保证最优 | 核心特点 |
|---|---|---:|---|
| 分支定界法 | 纯整数/混合整数线性规划 | 可以，前提是上下界和剪枝安全 | 将整数问题递归分解，利用界限剪枝 |
| 割平面法 | 纯整数/混合整数线性规划 | 可以，前提是割约束有效且算法完整 | 加入排除分数解的有效不等式 |
| 分支割平面法 | 大多数现代 MILP 求解器 | 可以，视求解器状态和模型 | 将分支定界与割平面结合 |
| 隐枚举法 | 规模较小的 0-1 整数规划 | 可以，前提是枚举完整且剪枝安全 | 利用目标界和约束逐步排除方案 |
| 匈牙利算法 | 指派问题这一特殊 0-1 规划 | 可以 | 利用指派问题结构高效求解 |
| 动态规划 | 具有阶段结构和状态转移的问题 | 通常可以 | 将问题拆成阶段和状态递推 |
| 启发式/元启发式 | 大规模或复杂整数规划 | 通常不能 | 快速获得高质量可行解 |
| 蒙特卡洛/随机采样 | 概率、风险、情景或随机搜索 | 不能作为一般最优性证明 | 通过采样估计表现或寻找候选方案 |

### 1. 分支定界法

分支定界法通常先求某个节点的连续松弛问题：

- 最大化问题中，LP 松弛值提供上界；
- 最小化问题中，LP 松弛值提供下界；
- 当前已知整数可行解提供相反方向的界。

只有当节点界限已经不能改善当前最好整数解时，才能安全剪枝。若上界低于已知可行解（最大化）或下界高于已知可行解（最小化），通常说明模型或界限计算有错误。

### 2. 割平面法与分支割平面法

割平面法通过增加不排除任何整数可行解、但排除当前分数解的有效不等式，使连续松弛逐渐接近整数可行域。

现代 MILP 求解器通常将割平面与分支定界结合，形成 Branch-and-Cut（分支割平面法），而不是只使用单一割平面过程。

### 3. 匈牙利算法

匈牙利算法是指派问题的专用算法。指派问题是 0-1 整数规划的特殊结构，不能据此认为匈牙利算法可以直接解决一般 0-1 规划或一般整数规划。

### 4. 蒙特卡洛和随机方法

蒙特卡洛适合概率估计、风险模拟、情景分析以及某些随机搜索过程，但一般不能保证整数规划的全局最优，也不能替代 MILP 或 MINLP 的精确求解器。

如果使用随机方法，应明确输出性质：

- 找到一个可行解：只能称为可行方案；
- 找到一个较好解：只能称为当前最好或近似方案；
- 只有经过精确算法或严格证明，才能称为全局最优解。

## 六、MATLAB 求解入口

整数线性规划可使用 MATLAB 的 `intlinprog`。以最小化问题为例：

\[
\begin{aligned}
\min\quad &f^{\mathsf T}x\\
\text{s.t.}\quad &Ax\leq b,\\
&A_{\mathrm{eq}}x=b_{\mathrm{eq}},\\
&lb\leq x\leq ub,\\
&x_j\in\mathbb{Z},\qquad j\in\texttt{intcon}.
\end{aligned}
\]

MATLAB 框架：

```matlab
% f：目标函数系数
% intcon：需要取整数的变量下标
% A*x <= b
% Aeq*x = beq
f = [1; 1];
intcon = [1, 2];
A = [2, 4];
b = 6;
Aeq = [];
beq = [];
lb = [0; 0];
ub = [];

[x, fval, exitflag, output] = intlinprog( ...
    f, intcon, A, b, Aeq, beq, lb, ub);

if exitflag <= 0
    error('整数规划求解失败：%s', output.message);
end

fprintf('最优目标值：%.6f\n', fval);
disp('最优变量：');
disp(x);
```

实际使用时，还要检查：

1. `exitflag` 是否代表求解成功或已达到可接受的最优性状态；
2. 变量是否满足整数性、边界和非负约束；
3. 目标函数是否与原问题方向一致；
4. 若求解器因时间限制停止，必须报告最优性间隙，不能直接称为已证明全局最优。

## 七、整数规划的建模检查清单

- [ ] 明确哪些变量必须取整数，哪些变量可以连续；
- [ ] 判断问题是纯整数、混合整数还是 0-1 整数规划；
- [ ] 先求或分析 LP 松弛，并正确解释其上下界性质；
- [ ] 不把连续解简单取整后直接当作整数最优解；
- [ ] 根据模型类型选择精确算法、启发式算法或随机方法；
- [ ] 若使用分支定界，验证上界/下界的安全性；
- [ ] 若使用随机方法，明确结果不能自动证明全局最优；
- [ ] 检查求解器支持的模型类型、变量声明和状态码。

## 八、知识总结

整数规划的学习主线为：

```text
识别整数变量
→ 判断纯整数、混合整数或 0-1 结构
→ 分析线性规划松弛
→ 判断连续解是否已经整数
→ 根据问题结构选择精确或近似方法
→ 检查可行性、目标值和最优性间隙
→ 正确解释“最优解”“近似解”和“可行解”
```

整数规划比普通线性规划增加了离散性约束，连续最优解不能简单取整替代整数求解。学习整数规划的关键，不只是记住分支定界、割平面和隐枚举等算法名称，还要理解每种方法能否保证最优、适合什么模型以及如何验证输出。
