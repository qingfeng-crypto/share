# 第六节 生产与销售计划问题

## 一、问题描述（例 9）

某公司用两种原油（A 和 B）混合加工成两种汽油（甲和乙）。

- 甲汽油含原油 A 不低于 50%，售价 4800 元/吨。
- 乙汽油含原油 A 不低于 60%，售价 5600 元/吨。
- 公司现有原油 A 库存 500 吨，原油 B 库存 1000 吨。
- 可从市场购买原油 A，最多 1500 吨。价格分段：

| 购买量区间 | 单价（元/吨） |
|-----------|-------------|
| ≤ 500 吨 | 10000 |
| 500 ~ 1000 吨（超出部分） | 8000 |
| 1000 ~ 1500 吨（超出部分） | 6000 |

**问：如何安排原油采购和加工使利润最大？**

## 二、难点分析

问题的难点在于原油 A 的采购价格是**分段函数**——不同购买量对应不同单价，这导致目标函数非线性，不能直接用线性规划求解。

## 三、三种建模方法

### 方法一：分解采购量（非线性规划）

将原油 A 采购量 x 分解为三部分：x₁（10 千元/吨，0 ≤ x₁ ≤ 500）、x₂（8 千元/吨，0 ≤ x₂ ≤ 500）、x₃（6 千元/吨，0 ≤ x₃ ≤ 500）。总支出：

\[
c(x) = 10x_1 + 8x_2 + 6x_3
\]

但需满足条件：(x₁ - 500)·x₂ = 0，(x₂ - 500)·x₃ = 0（即必须按价格段顺序购买），导致模型为**非线性规划**。用 LINGO 全局优化求解得：购买 1000 吨原油 A，与库存 500 吨 A 和 1000 吨 B 一起，生产 2500 吨汽油乙，最大利润为 **5000 千元**。

### 方法二：引入 0-1 变量（混合整数线性规划）

引入 0-1 变量 z₁, z₂, z₃ 表示是否以对应价格采购：

```
500z₂ ≤ x₁ ≤ 500z₁
500z₃ ≤ x₂ ≤ 500z₂
x₃ ≤ 500z₃
z₁, z₂, z₃ = 0 或 1
```

将非线性约束替换为线性约束，构成**混合整数线性规划（MILP）**，可用分枝定界法直接求解。**这种方法推荐优先使用**。

### 方法三：分段线性函数法

直接对分段线性采购成本函数建模。设分点 b₁ = 0, b₂ = 500, b₃ = 1000, b₄ = 1500，引入权重 wₖ 和 0-1 变量 zₖ：

```
x = 500w₂ + 1000w₃ + 1500w₄
c(x) = 5000w₂ + 9000w₃ + 12000w₄
w₁ ≤ z₁, w₂ ≤ z₁+z₂, w₃ ≤ z₂+z₃, w₄ ≤ z₃
w₁+w₂+w₃+w₄ = 1,  wₖ ≥ 0
z₁+z₂+z₃ = 1,  zₖ = 0 或 1
```

该方法可将任意 n 段线性函数统一建模，具通用性。

## 四、小结

生产与销售计划问题是一个综合性的**混合整数规划建模训练**。核心难点是分段函数线性化，解决的思路是引入 0-1 变量或权重变量，将非线性问题转化为混合整数线性规划（MILP），再借助分枝定界法求解。掌握这种"非线性 → 线性"的转化技巧，对解决实际优化问题很有帮助。
