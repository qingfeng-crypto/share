# 第二节 分枝定界法

## 一、什么是分枝定界法

分枝定界法（Branch and Bound，B&B）是求解整数规划，特别是整数线性规划的经典精确方法。它把原本难以直接求解的整数可行域分割为多个子问题，并对每个子问题计算一个可靠的界限：

- **分枝（Branch）**：把一个含有分数变量的子问题拆成更小的子问题；
- **定界（Bound）**：用连续松弛或其他乐观估计计算子问题的上界或下界；
- **剪枝（Prune）**：当子问题不可能优于当前最好整数解，或子问题不可行时，不再继续搜索。

分枝定界法不是简单的随机搜索，也不是把连续解直接取整。只要分枝覆盖完整、界限安全、剪枝条件正确，就可以在有限搜索后证明全局最优。

它广泛用于生产排程、旅行商问题、设施选址、背包、分配和车辆路径等离散优化问题。现代整数规划求解器通常把分枝定界与割平面、启发式搜索等结合使用。

## 二、最大化问题的上下界

考虑最大化整数规划问题 A：

\[
\begin{aligned}
\max\quad &f(x)\\
\text{s.t.}\quad &x\in X,\\
&x\text{ 的指定变量为整数}.
\end{aligned}
\]

去掉整数约束后得到连续松弛问题 B。由于 B 的可行域包含 A 的可行域：

- 连续松弛最优值 \(\bar z\) 是整数问题最优值 \(z^*\) 的**上界**；
- 任意整数可行解的目标值 \(\underline z\) 是 \(z^*\) 的**下界**。

因此：

\[
\underline z\leq z^*\leq\bar z.
\]

对最小化问题，方向相反：连续松弛值通常是下界，整数可行解值是上界。

### 1. 下界的获得

最大化问题的下界来自任意整数可行解。可以使用：

- 零向量或简单初始方案；
- 对连续解进行可行化修复后的方案；
- 贪心算法或局部搜索得到的整数可行解；
- 其他启发式方法得到的可行解。

下界越高，后续剪枝越积极，但下界本身必须来自真正满足所有约束的整数可行解。

### 2. 上界的安全性

最大化问题的节点上界必须满足：

\[
UB(N)\geq\text{节点 }N\text{ 内所有整数可行解的最大目标值}.
\]

如果一个“上界”小于已经找到的可行解，说明模型、变量顺序、约束、目标方向或界限推导存在错误，不能继续用它剪枝。

## 三、分枝、定界和剪枝规则

### 1. 分枝规则

设当前连续松弛解中的整数变量为：

\[
x_j=4.8092.
\]

由于 \(x_j\) 必须为整数，将其分成两个互斥且覆盖完整的子问题：

\[
x_j\leq4,
\qquad x_j\geq5.
\]

一般地，如果 \(x_j=\xi\) 且 \(\xi\notin\mathbb{Z}\)，则分枝为：

\[
x_j\leq\lfloor\xi\rfloor,
\qquad
x_j\geq\lceil\xi\rceil.
\]

两个分支既不重叠，又覆盖所有可能的整数取值。

### 2. 节点处理

对每个节点重新求解该节点的连续松弛：

1. 松弛问题无可行解：直接剪枝；
2. 松弛解满足整数约束：得到一个整数可行解，并更新当前最好解；
3. 松弛界不能改善当前最好整数解：剪枝；
4. 否则选择一个分数变量继续分枝。

### 3. 最大化问题剪枝

若当前最好整数可行解目标值为 `incumbent`，节点连续松弛上界为 `UB`，则：

\[
UB\leq incumbent
\]

时可以剪枝。若使用浮点计算，应使用容差：

```text
if UB <= incumbent + tolerance:
    prune node
```

若 `UB` 与 `incumbent` 的差距为零或不超过求解器容差，则当前最好整数解已经得到最优性证明。

### 4. 最小化问题剪枝

若当前最好整数可行解目标值为 `incumbent`，节点连续松弛下界为 `LB`，则：

\[
LB\geq incumbent
\]

时可以剪枝。最大化和最小化问题不能混用剪枝方向。

## 四、经典例题

求解整数规划：

\[
\begin{aligned}
\max\quad &z=40x_1+90x_2\\
\text{s.t.}\quad
&9x_1+7x_2\leq56,\\
&7x_1+20x_2\leq70,\\
&x_1,x_2\geq0,\quad x_1,x_2\in\mathbb{Z}.
\end{aligned}
\]

### 第 1 步：求解根节点松弛问题

忽略整数约束，连续松弛最优解为：

\[
x_1\approx4.8092,
\qquad x_2\approx1.8168,
\qquad \bar z\approx355.88.
\]

因此根节点上界可以记为：

\[
UB_0=355.88.
\]

取零向量作为初始整数可行解，得到：

\[
LB_0=0.
\]

### 第 2 步：按非整数变量分枝

对 \(x_1=4.8092\) 分枝：

#### 节点 B1：\(x_1\leq4\)

该节点连续松弛最优解为：

\[
x_1=4,
\qquad x_2=2.1,
\qquad UB_1=349.
\]

该解还不是整数解，因为 \(x_2=2.1\)。

#### 节点 B2：\(x_1\geq5\)

该节点连续松弛最优解约为：

\[
x_1=5,
\qquad x_2=\frac{11}{7}\approx1.5714,
\qquad UB_2\approx341.43.
\]

此时全局上界为：

\[
UB=\max(UB_1,UB_2)=349.
\]

注意：节点松弛解的目标值是节点上界，即使其中某个变量已经是整数，也不能把该解直接称为整数可行解，除非所有整数变量都满足整数性。

### 第 3 步：继续处理 B1

对 B1 的分数变量 \(x_2=2.1\) 分枝。

#### 节点 B11：\(x_2\leq2\)

该节点继承了 B1 的约束 \(x_1\leq4\)，其连续松弛最优解为：

\[
x_1=4,
\qquad x_2=2,
\qquad z=40\times4+90\times2=340.
\]

该解是整数可行解，因此更新下界：

\[
LB=340.
\]

#### 节点 B12：\(x_2\geq3\)

节点松弛最优值约为：

\[
UB_{12}\approx327.14.
\]

因为：

\[
UB_{12}<LB=340,
\]

所以 B12 不可能产生优于当前方案的整数解，可以剪枝。

### 第 4 步：处理 B2

对 B2 的分数变量 \(x_2\approx1.5714\) 分枝。

#### 节点 B21：\(x_2\leq1\)

节点松弛值为：

\[
UB_{21}=40\times\frac{49}{9}+90\approx307.78<340.
\]

因此 B21 剪枝。

#### 节点 B22：\(x_2\geq2\)

结合 B2 的 \(x_1\geq5\)，第二个约束给出：

\[
7x_1+20x_2\geq7\times5+20\times2=75>70,
\]

因此 B22 无可行解，直接剪枝。

### 第 5 步：得到并证明最优解

所有未处理节点都已因不可行或上界不超过 340 而剪枝，因此：

\[
x^*=(4,2),
\qquad z^*=340.
\]

这里的最优性不是因为“找到一个看起来很好的整数解”，而是因为所有可能优于 340 的分支都已经被安全排除。

## 五、算法步骤总结

最大化整数规划的分枝定界流程：

```text
建立整数规划模型
→ 去掉整数约束，求根节点连续松弛
→ 初始化整数可行解和下界
→ 若松弛解整数，则更新下界
→ 若松弛不可行，则剪枝
→ 若节点上界不超过下界，则剪枝
→ 选择分数变量并分成两个互斥子问题
→ 重新求解子节点松弛
→ 更新全局上下界
→ 直到所有节点处理完或最优性间隙达到容差
```

### 节点记录建议

实际编程时，每个节点至少记录：

| 字段 | 含义 |
|---|---|
| 分枝约束 | 该节点相对于父节点增加的约束 |
| 松弛状态 | 可行、不可行、超时或其他状态 |
| 松弛解 | 连续变量值 |
| 节点界限 | 最大化上界或最小化下界 |
| 整数可行解 | 若松弛解已整数或经过独立构造得到 |
| 剪枝原因 | 不可行、界限剪枝或达到整数解 |

## 六、MATLAB 实现边界

对于一般整数线性规划，优先使用 `intlinprog` 作为可靠基准，再根据学习目标实现简化版分枝定界。手写实现时，必须确认：

- 连续松弛使用 `linprog`，整数问题使用 `intlinprog` 或明确的节点搜索；
- 最大化目标传给 `linprog` 时要取负号，输出值再恢复符号；
- 节点约束必须继承父节点约束；
- 节点上界来自该节点连续松弛，而不是来自任意整数点；
- 剪枝方向与最大化/最小化目标一致；
- `exitflag`、求解状态和最优性间隙必须记录。

在 MATLAB R2024b 中，整数规划的基本入口为：

```matlab
f = [-40; -90];             % 最大化 40*x1 + 90*x2 -> 取负号
intcon = [1, 2];
A = [9, 7; 7, 20];
b = [56; 70];
Aeq = [];
beq = [];
lb = [0; 0];
ub = [];

[x, fval, exitflag, output] = intlinprog( ...
    f, intcon, A, b, Aeq, beq, lb, ub);

if exitflag <= 0
    error('整数规划求解失败：%s', output.message);
end

z = -fval;
fprintf('最优目标值：%.6f\n', z);
disp('最优解：');
disp(x);
```

这段代码用于得到可靠基准，不等同于手写的教学版 B&B。若要自己实现 B&B，应先用小规模实例与 `intlinprog` 对照，再扩大规模。

## 七、结果检查清单

- [ ] 每个分枝覆盖完整整数可行域，且两个子分支不重叠；
- [ ] 每个节点都重新求解了对应连续松弛；
- [ ] 最大化上界或最小化下界的方向正确；
- [ ] 下界/上界均来自合法解或安全松弛；
- [ ] 已知整数可行解优于节点上界时，确认是上界计算错误而不是正常现象；
- [ ] 剪枝原因可追溯：不可行、界限不足或已得到整数解；
- [ ] 最终报告当前最好整数解、全局界限和最优性间隙；
- [ ] 手写算法与 `intlinprog` 或小规模枚举结果交叉验证。

## 八、知识总结

分枝定界法的核心不是“把空间分成很多块”，而是：

```text
用分枝保证搜索覆盖
→ 用连续松弛得到安全界限
→ 用整数可行解更新当前最好值
→ 用安全界限剪除不可能更优的节点
→ 用全局上下界收敛证明最优性
```

最容易犯的错误是：把节点中的整数可行点当成上界、使用不安全的松弛估计、混淆最大化和最小化的剪枝方向，以及在求解器未证明最优时直接声称得到全局最优。
