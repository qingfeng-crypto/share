# 积累足够之后如何对技能进行修改

## 一、总体目标

知识库的作用不是取代现有技能，而是补全现有技能的不足。

最终目标不是：

```text
教材知识库 → 覆盖现有技能
```

而是：

```text
现有技能 + 经过验证的知识补充 → 更完整、更平衡的技能
```

现有技能中可能已经存在比新材料更成熟、更可靠或更适合执行的内容。因此，知识库内容不得因为“新学到”就自动覆盖正式技能。

## 二、知识从学习区进入技能区的流程

```text
提供原始材料
→ 整理为正确知识
→ 与现有技能比较
→ 判断现有技能是否已有更好内容
→ 只提取缺失部分或改进部分
→ 经过验证后补入正式技能
```

教材、课程、真题和个人复盘材料都属于原始材料。进入正式技能前，必须经过数学逻辑核对、版本核对、代码验证和与现有技能的差异审查。

## 三、知识比较后的四种处理方式

### 1. 现有技能更完善

- 保留现有技能；
- 在知识库记录新材料的补充视角；
- 不重复迁移；
- 不因为教材表述不同就修改正式技能。

### 2. 知识库更具体，现有技能已有基础规则

- 不替换原规则；
- 补充具体案例、边界条件、实现细节或 MATLAB 实例；
- 保留现有技能的通用原则。

### 3. 知识库发现现有技能缺口

- 只补缺失部分；
- 不删除已经成熟的其他语言实现；
- 记录补充内容的来源、适用版本和验证结果。

### 4. 现有技能与新材料冲突

- 不立即覆盖任何一方；
- 标记为待审查；
- 根据官方文档、实际版本运行结果和数学逻辑判断；
- 最终保留更可靠的版本，并记录适用范围和采用理由。

## 四、知识可靠性优先级

处理冲突时，默认参考以下优先级：

```text
官方文档与实际版本验证
        ↓
已经验证的现有技能规则
        ↓
经过数学审查和代码验证的知识库内容
        ↓
教材原始材料
        ↓
未经核对的 OCR 或个人推断
```

教材是高价值原材料，但不是无条件覆盖源。教材可能包含旧版 MATLAB 写法、简化条件、排版错误、OCR 错误或特定课程语境下的结论。

## 五、语言平衡原则

数学知识应先按语言中立方式整理，再分别记录 MATLAB 与 Python 实现：

```text
数学模型
├── MATLAB 实现
└── Python 实现
```

迁移时不要求两种语言内容完全相同，而应做到：

- 数学知识保持共同核心；
- 保留 MATLAB 和 Python 各自成熟的优势；
- 优先补足薄弱语言的知识缺口；
- 不因 Python 示例较多就默认推荐 Python；
- 不因补充 MATLAB 就删除已经成熟的 Python 内容；
- 语言选择仍由题目、算法、数据规模、工具能力和交付要求决定。

## 六、迁移前差异审查表

每次准备修改正式技能前，先建立差异表：

```markdown
| 知识点 | 现有技能状态 | 新知识状态 | 处理决定 |
|---|---|---|---|
| LP 标准形式 | 已有，较完整 | 教材表述不同 | 保留技能，统一表述 |
| MATLAB linprog | 不完整 | 有完整流程 | 补入 MATLAB 部分 |
| Python linprog | 已有示例 | 教材未涉及 | 保留现有内容 |
| 极点最优性 | 较少 | 教材有系统解释 | 补充理论部分 |
| 影子价格 | 有基础 | 尚未涉及 | 暂不迁移 |
```

差异表应明确区分：保留、补充、修订、暂不迁移和待验证，不得只写“新知识更好”。

## 七、正式修改前的检查条件

只有在以下条件基本满足后，才考虑把知识库内容迁移到正式技能：

- 数学定义、适用条件和变量含义明确；
- 至少有一个完整案例或可复现推导；
- MATLAB 与 Python 实现接口分别核对；
- 关键代码在目标版本中实际运行或有官方文档依据；
- 结果验证、常见错误和版本边界已经记录；
- 与现有技能的冲突已经解决；
- 修改范围只针对明确的缺口或改进点；
- 修改后不会破坏已有成熟流程。

## 八、修改策略

正式技能修改应采用增量补全，而不是整体重写：

1. 先修改最具体的参考文档，而不是直接重写总入口；
2. 优先补充缺失的 MATLAB 或 Python 实现；
3. 再更新语言路由、质检清单和错误防护规则；
4. 修改后检查交叉引用和内部一致性；
5. 使用真实题目验证新规则；
6. 确认稳定后再更新总入口或摘要说明。

## 九、当前线性规划示例

现有技能已经包含：

- 线性规划基础；
- Python `scipy.optimize.linprog` 示例；
- Python 生产计划代码。

知识库新增并经过整理的内容包括：

- 教材式实际问题建模流程；
- MATLAB `linprog` 标准形式；
- MATLAB R2024b 调用方式；
- 可行域、极点和图解法；
- 求解结果检查和资源分析。

正确的迁移结果应当是：

```text
线性规划
├── 通用数学模型
├── 建模流程
├── MATLAB linprog
├── Python scipy.optimize.linprog
├── 结果验证
└── 常见问题
```

不应删除现有 Python 内容，也不应让 MATLAB 内容取代数学模型本身。

## 十、核心原则

> 知识库负责学习和比较，正式技能负责稳定执行；迁移只发生在确认能够补强技能时。

```text
先积累
再比较
后验证
只补缺
不盲目替代
```
