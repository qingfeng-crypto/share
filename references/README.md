# 三轨角色导航

> 注：本技能由**一个 AI 助手**承载三轨角色，不表示三个独立 AI。
> 完整工作流、审查规范、交接契约、72h 时间线等全局规则见主 `SKILL.md`。

## 角色一览

| 角色 | SKILL.md | 职责 |
|------|----------|------|
| 建模分析与审查 | `roles/审核建模手/SKILL.md` | 建模分析产出 + 子问题级审查 |
| 编程手核心 | `roles/编程手核心/SKILL.md` | 路由确认 + 代码实现 + 验证 + 图表 |
| 交付论文手 | `roles/交付论文手/SKILL.md` | 整理编程成果为论文手可接收的材料包 |

## 集成工具
