# CUMCM 国赛选题参考

本科组 A/B/C 三题特征与算法策略。

---

## A题 — 物理/工程机理型

| 维度 | 说明 |
|------|------|
| **背景** | 工程物理问题，机理建模为主（微分方程、物理定律） |
| **特征** | 有命题人提供的**参考结果**，评阅看重结果准确性和模型物理合理性 |
| **适合** | 有理工科背景、能建微分方程/偏微分方程的队 |
| **风险** | 结果不对直接扣分；模型假设不当会被质疑 |

**常用方法**：微分方程（ODE/PDE）、数值模拟（有限差分/有限元）、参数反演、优化（配合物理约束）

---

## B题 — 题型可变（多为优化/运筹）

| 维度 | 说明 |
|------|------|
| **背景** | 调度、规划、资源配置、决策优化，偶有物理或工程背景 |
| **特征** | **三题中变数最大**，没有固定套路，每年可能风格迥异 |
| **适合** | 建模思路灵活、擅规划论/图论的队 |
| **风险** | 题型突变时若只准备了一套方法可能被动 |

**常用方法**：整数/线性/非线性规划、多目标优化、图论（最短路径/网络流/最小生成树）、启发式算法（遗传/粒子群/模拟退火）

---

## C题 — 数据驱动/统计/数据挖掘型

| 维度 | 说明 |
|------|------|
| **背景** | 给大量真实数据，做统计分析、回归、分类、预测 |
| **特征** | **最开放**，无标准答案；解法多样，评阅看逻辑和数据说服力 |
| **适合** | 擅长编程、数据处理、可视化的队 |
| **风险** | 选题人数超50%，竞争激烈；纯套模型不够，必须有亮点 |

**常用方法**：数据清洗与预处理、回归/分类/聚类、时间序列、机器学习（随机森林/XGBoost/LSTM）、评价模型、可视化分析

---

## 选题策略

| 情况 | 建议 |
|------|------|
| 队里有工科生，建模能力强 | 冲A，人少区分度大 |
| 队里编程能力强，数据敏感 | 选C，但必须有创新点（模型组合/可视化亮点）才能突围 |
| 想求稳，各科均衡 | 选B，灵活应对 |
| 时间紧准备不足 | 慎重选A（有结果要求），C题起手容易但做深难 |
