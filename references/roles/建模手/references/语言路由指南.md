# 语言路由指南 (Language Routing Guide)

作为编程手，在代码实现前对每个子问题判定推荐使用的编程语言，自行建立「语言路由表」并向用户确认后执行。推荐必须基于题目与算法的客观条件，不得由 AI 的语言偏好或当前工具可用性决定。建模手在交付物中须提供每子问题的算法类别、数据规模与所需专用库/工具箱，作为路由的客观输入。

---

## 一、最高优先级原则

Python 和 MATLAB 是并列候选语言。语言推荐必须依次考察：

1. 模型和算法的原生适配度；
2. 数据规模、矩阵稀疏性、数值稳定性和性能要求；
3. 可用工具箱与库的实际能力；
4. 上下游数据接口和整体流程一致性；
5. 代码可解释性、复现性和竞赛交付成本。

以下因素不得作为偏向 Python 的理由：AI 更熟悉 Python、Python 示例更多、当前技能对 Python 支持更多、MATLAB MCP 是否可用。当前已配置正式 MATLAB MCP Server；MCP 状态只影响执行方式，不影响语言路由。正常情况下 MATLAB 任务直接通过 MCP 执行；只有 MCP 明确报错时，才生成 `.m` 文件供用户手动运行。

## 二、路由判断原则

```
数据预处理 / 清洗 / 整合  → Python（pandas 生态无可替代）
统计分析与探索性分析      → Python（scipy / statsmodels 更灵活）
机器学习与深度学习        → Python（scikit-learn / PyTorch 更成熟）
可视化与图表生成          → Python（matplotlib / seaborn 更灵活）
PDF / Excel / Word 文档   → Python（技能内建 tools 支持）

线性规划 / 整数规划       → MATLAB（intlinprog 性能更优）
非线性规划                → Python/MATLAB 均可，问题复杂选 MATLAB
微分方程 / 偏微分方程     → MATLAB（ode45 / ode15s / pdepe 工具箱成熟）
矩阵运算 / 线性代数       → 均可，小规模用 Python，大规模稀疏矩阵选 MATLAB
信号处理 / 控制系统       → MATLAB（Signal Processing / Control System Toolbox）
图论与网络分析            → Python（networkx 更轻量，MATLAB graph 亦可）
蒙特卡洛仿真              → 均可，复杂仿真选 MATLAB
模糊综合评价 / AHP        → 均可，Python 代码可读性更好
灰色预测 / 时间序列       → 均可，数据量大且需工具箱辅助选 MATLAB
```

## 三、分步执行规划格式

在 `题目分析.md` 的语言路由章节，按以下格式填写：

```markdown
### 4.2 分步执行计划

| 步骤 | 操作描述 | 推荐语言 | 理由 |
|------|---------|---------|------|
| 1 | 数据读取与清洗 | Python | pandas 高效 |
| 2 | 线性规划求解 | MATLAB | intlinprog 更快 |
| 3 | 结果可视化 | Python | matplotlib 生态 |
```

## 四、用户确认闸门

编写或执行每个子问题前，必须先展示：

```text
推荐语言：[Python / MATLAB]
客观依据：[至少两条，来自模型、算法、数据、性能或工具能力]
另一语言：[可行性与不优先原因]
执行方式：[Python / MATLAB MCP / MATLAB 手动降级]
输出与下一步：[文件、格式和依赖]
请确认：A 按推荐执行；B 改用另一语言；C 比较两种实现；D 暂缓。
```

用户确认前不得写代码、运行代码、调用 MCP 或自动进入下一个子问题。用户改选后，必须在路由表中记录最终选择及用户理由。

## 五、执行方式说明

| 语言 | 执行方式 | 降级方案 |
|------|---------|---------|
| Python | 直接 `python 文件名.py` 执行 | N/A |
| MATLAB | 先用 `evaluate_matlab_code` 做轻量连通性检查，再通过 MCP 调用 `evaluate_matlab_code` / `run_matlab_file`；自动会话模式可连接已运行 MATLAB 或启动新会话 | MCP 明确报错、会话无法启动或用户要求手动运行时，提示用户在 MATLAB 中运行生成的 `.m` 文件 |

---

## 六、冲突解决规则

当某子问题两种语言均可时，按以下优先级选择：

1. **子任务整体一致性**：若子问题内的多个步骤语言不一致，重新评估是否需要拆分子问题
2. **后续任务依赖**：优先保持上下游语言一致，减少数据格式转换
3. **性能优先**：计算密集且 MATLAB 明显更快的，选择 MATLAB
4. **生态优先**：数据处理、可视化、文档生成优先 Python
