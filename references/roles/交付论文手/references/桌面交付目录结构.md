# 桌面交付目录结构（轻量版）

默认桌面交付目录：`C:\Users\qingf\Desktop\交付论文手_YYYYMMDD_HHMM\`

该目录是中间交接物：

- 不回写项目目录
- 不参与 git
- 不作为正式比赛提交目录

## 逐子问题轻量交付结构

每个子问题完成后，生成一份轻量交付文件：

```text
C:\Users\qingf\Desktop\交付论文手_YYYYMMDD_HHMM\
├── 子问题1_交付.md
├── 子问题2_交付.md
├── 子问题3_交付.md
└── ...（按子问题数量生成）
```

每份 `子问题N_交付.md` 包含 5 项内容，见 `逐子问题交付模板.md`。

## 设计意图

1. 逐子问题交付，不必等全部计算完成。
2. 每份交付独立，论文手拿到即可写对应章节。
3. 模型说明、公式变量、术语表由建模手直接交付论文手，不经过本角色。
