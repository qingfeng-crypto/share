# 编程手核心质检清单

完成代码和图表后，逐项完成以下检查。

---

## A. 代码质量检查

- [ ] **代码可运行**：代码能够正确运行，无语法错误和运行时错误
- [ ] **结果合理**：输出结果符合题目要求和建模预期
- [ ] **结构清晰**：模块划分合理，有函数注释
- [ ] **导入齐全**：所有必要的库导入语句完整
- [ ] **结果输出完整**：.csv 或终端输出齐全

## B. 可视化检查

### B1. 三类图表完备性（每题）

- [ ] **① 原始数据可视化 ≥ 1 张**：数据分布、相关性或时序趋势图
- [ ] **② 中间产物可视化 ≥ 1 张**：收敛曲线、模型对比或误差分析图
- [ ] **③ 最终结果可视化 ≥ 2 张**：核心结论的对比/预测/综合评价图
- [ ] **总计 ≥ 4 张，建议 5 张以上**：每道题保留足够候选图，供论文阶段筛选

### B2. 图表质量

- [ ] **核心结论明确**：每张图都有清晰的 one-sentence 结论
- [ ] **面板无冗余**：每个面板承载独特的证据
- [ ] **颜色语义一致**：同一方法家族在不同面板中保持同一色系
- [ ] **中文显示正常**：无方块或乱码
- [ ] **PNG 分辨率达标**：普通图至少 300 dpi，论文/最终交付图 600 dpi
- [ ] **MATLAB 导出达标**：显式设置图窗尺寸，使用 `exportgraphics`，不以默认 `saveas` PNG 作为最终图
- [ ] **坐标轴精简**：仅保留左+下 spines，右+上已关闭
- [ ] **无网格线**：无网格线干扰
- [ ] **面板标签正确**：小写粗体 `a, b, c`，transAxes 定位，字号 22
- [ ] **图例无边框**：`frameon=False`
- [ ] **统计量完整**：p值、n数、误差棒定义清晰标注
- [ ] **文字色深合理**：深色背景浅色文字，浅色背景深色文字
- [ ] **图幅尺寸合适**：根据图表类型选择推荐 figsize
- [ ] **图表已关闭**：每个 `save_figure()` 包含 `plt.close(fig)`
- [ ] **PNG 600 dpi 已确认**：每个图输出高分辨率 PNG 600 dpi
- [ ] **文件生成已验证**：检查图像文件存在且文件大小合理，报告实际路径

## C. 文件结构检查

- [ ] `data/`、`results/`、`figures/` 三个目录已创建
- [ ] 代码文件命名为 `问题X_求解.py/.m` 格式
- [ ] `README.md` 项目说明文档已创建
- [ ] 建模手分析文档和术语表未修改

## D. 表格处理检查

- [ ] 输入表格只读不写
- [ ] 普通结果汇总优先输出 CSV
- [ ] 指定 Excel 模板保持原有结构
- [ ] 使用模板时不添加/删除列或修改列名
- [ ] 输出到新文件，不覆盖原输入文件
- [ ] 指定 Excel 模板中已有公式时，不硬编码覆盖公式

## E. 供交付论文手使用的结构化结果材料检查

- [ ] 方法-语言路由表已整理
- [ ] 路由前已对称预检 Python 与 MATLAB：双方版本、运行状态、依赖/工具箱状态和具体错误均已记录
- [ ] 未将“Python已检查”或“MATLAB未检查”当作语言推荐依据
- [ ] 用户确认最终语言后已完成对应正式运行时检查；混合语言任务两边均已检查
- [ ] 求解器事实核验已记录：名称/版本、目标函数、约束、变量类型、最优性/可行性/误差能力和核验来源
- [ ] 高风险问题（NLP/MINLP/MILP/QP/ODE/PDE/控制/信号处理/最优性证明）没有跳过事实核验
- [ ] 代码文件清单已整理
- [ ] 结果文件清单已整理
- [ ] 图表文件清单已整理
- [ ] 每个子问题最终结果已整理
- [ ] 验证记录已整理
- [ ] 结构化结果材料与实际代码、结果、图表文件可互相追溯
