# 可视化规范 —— SCI/Nature 级学术图表

本项目的可视化目标不仅是"出图"，而是以 SCI、Nature 等高水平期刊的插图标淮要求自己，让数学建模论文的图表同样达到学术出版级别。每张图都应当是一个**视觉论证**，而非孤立的漂亮图表。

> **出图语言：Python 首选，MATLAB 合规例外。** 论文正式图表通常优先用 Python（matplotlib）绘制，以保证风格统一、复用稳定和 PNG 600 dpi 导出一致。若图高度依赖 MATLAB 专用工具箱可视化，或 MATLAB 已能以不高于 Python 重绘的成本达到同等视觉质量与交付标准，则允许直接使用 MATLAB 出图；否则应先导出数据，再由 Python 绘图。所有 MATLAB 例外出图都必须遵守下文「MATLAB 视觉样式规范」与「MATLAB 文本与公式渲染规范」。

## 一、前置合同 (Figure Contract)

在编写任何绘图代码之前，必须先建立 Figure Contract：

### 1. 核心结论
用一句话写出这张图必须证明的核心主张。

### 2. 证据链
将核心结论拆解为若干条证据，每个面板对应一条独特证据。

**防冗余原则**：如果遮盖任意一个面板后，该图的核心结论仍能从其他面板完整读取，则该面板是冗余的。

## 三、Python 可视化完整配置

### 输出分辨率与格式硬性要求

**国赛（CUMCM）实际场景**：最终提交为 PDF（部分学校/赛区同时接受 Word），图表以 PNG 600 dpi 嵌入 PDF 或 Word。团队内部写论文常用 Overleaf（LaTeX），矢量图（SVG/PDF）在编辑阶段可无限放大而不失真，是 Overleaf 场景的首选；PNG 则用于最终嵌入交付。

- **PNG 600 dpi**：最终交付给写手嵌入论文的格式，默认产出；探索阶段允许 **300 dpi**，提交前统一为 600 dpi
- **SVG / PDF 矢量图（可选）**：Overleaf/LaTeX 编辑阶段优先用矢量图，字体和线条清晰度无上限限制
- 图窗或画布必须显式设置尺寸，禁止依赖默认屏幕大小
- 禁止将聊天窗口截图、屏幕截图或低分辨率 `saveas` PNG 作为最终图表
- 保存后必须检查目标文件存在、文件大小合理，并向用户报告实际输出路径和格式
- 分辨率是导出质量要求，不等同于盲目放大；必须同时保证字体、线宽、图例和布局在目标尺寸下清晰可读

### 文件命名规范

> 命名即交付。文件名是写手与图之间的唯一接口，必须一望可知、永不丢失。

**格式**：`Fig{序号}_{题号}_{内容描述}.png`

- 序号从 1 开始递增，同一题内连续编号
- 题号用字母：`A`、`B`、`C`，对应三道题；支撑材料附录图用 `Appendix`
- 描述用中文，不超过 8 个字，不含空格

**示例**：
- `Fig1_A_温度场分布.png`
- `Fig2_B_遗传算法收敛曲线.png`
- `Fig3_C_聚类结果散点图.png`
- `Fig_Appendix_1_参数敏感性分析.png`（支撑材料专用）

**严禁**：`image001.png`、`新建图片.png`、`1.png`、`figure.png` 这类无意义命名。

### 交付自查清单

在将图片交付给论文手之前，逐项确认：

1. **坐标轴带单位**：所有轴标签包含物理单位（如 `Time / s`、`Velocity / m/s`），不得只有变量名
2. **图例不遮挡**：`frameon=False`，位置选用 `best` 或 `upper left`，不覆盖关键数据区
3. **初始+最终状态对比**：算法类图表必须包含迭代前（随机/初始）与迭代后（收敛）的对比，证明不是只放最终结果
4. **交付时效**：PNG 保存后立即交付给写手，不等写手来要；原始数据（`.csv`/`.mat`）同步备份，防止写手要求重画

### 色深对比度函数

```python
def luminance_text_color(hex_color):
    """根据背景色明度自动返回白色或深色文字"""
    c = hex_color.lstrip('#')
    r, g, b = int(c[0:2], 16) / 255, int(c[2:4], 16) / 255, int(c[4:6], 16) / 255
    luminance = 0.299 * r + 0.587 * g + 0.114 * b
    return 'white' if luminance < 0.5 else '#333333'
```

### 统一保存函数

```python
def save_figure(fig, filename, dpi=600, fmt='png'):
    """保存图表并关闭。国赛交付用 PNG 600 dpi；Overleaf 编辑阶段可改用 SVG/PDF 矢量图。
    图窗尺寸由创建时的 figsize 决定，本函数不再覆盖，避免破坏布局。
    dpi: 仅对 PNG/JPG 生效，默认 600（国赛交付标准）；探索阶段可传 300。
    fmt: 'png'（最终交付）/'svg'（Overleaf 编辑）/'pdf'（Overleaf/Pub）
    """
    if fmt == 'svg':
        fig.savefig(f'figures/{filename}.svg', format='svg', bbox_inches='tight')
    elif fmt == 'pdf':
        fig.savefig(f'figures/{filename}.pdf', format='pdf', bbox_inches='tight')
    else:
        fig.savefig(f'figures/{filename}.png', dpi=dpi, bbox_inches='tight')
    plt.close(fig)
    fig.savefig(f'figures/{filename}.png', dpi=dpi, bbox_inches='tight')
    plt.close(fig)  # 强制关闭
```

### MATLAB 导出规范（数据导出 + 极个别出图例外）

**常规情况（首选路径）**：MATLAB 只负责计算，结果导出为数据文件后交由 Python 绘图。这仍是大多数论文正式图表的首选路径。推荐：
```matlab
% 数值结果导出，供 Python 读取绘图
writematrix(result, 'data/result.csv');      % 或 save('result.mat','result')
```
Python 侧用 `pandas.read_csv('data/result.csv')` / `scipy.io.loadmat('result.mat')` 读取后绘图。

**例外情况（MATLAB 直接出图）**：当图高度依赖 MATLAB 专用工具箱可视化，或 MATLAB 已能以不高于 Python 重绘的成本达到同等视觉质量与交付标准时，允许在 MATLAB 直接出图。此时必须显式设置图窗大小、使用高质量导出。优先 `exportgraphics`，不要用默认 `saveas` 生成最终 PNG；并须同时遵守下方「MATLAB 视觉样式规范」与「MATLAB 文本与公式渲染规范」：

```matlab
fig = figure('Color', 'w', 'Units', 'pixels', ...
    'Position', [100 100 1600 1000]);
plot(x, y, 'LineWidth', 1.5);
grid off;   % 须同时遵守下方「MATLAB 视觉样式规范」
exportgraphics(fig, 'figures/result.png', 'Resolution', 600);
```

- Bode 图、复杂多面板图等工具箱图表也必须重新设置图窗尺寸并高分辨率导出

### MATLAB 视觉样式规范（仅极个别 MATLAB 出图例外时适用）

MATLAB 默认样式（四边灰框、`grid on`、细线 0.5、默认字体）远未达到本技能的 SCI/Nature 级要求；本技能此前只规定了 MATLAB 的"导出质量"而**未规定"视觉样式"**，这正是 MATLAB 图比 Python 丑的根因。必须在每次绘图前设置以下等效样式（对标 Python 全局 `rcParams`）：

```matlab
% ===== SCI/Nature 级 MATLAB 默认样式（放在绘图代码开头）=====
set(0, 'DefaultFigureColor',    'w');
set(0, 'DefaultAxesColor',      'w');
set(0, 'DefaultAxesFontSize',   8);
set(0, 'DefaultAxesLineWidth',  0.8);
set(0, 'DefaultLineLineWidth',  1.5);
set(0, 'DefaultAxesTickDir',    'out');
set(0, 'DefaultAxesBox',        'off');   % 去上/右边框，仅留左+下脊线
set(0, 'DefaultAxesXGrid',      'off');   % 关闭网格
set(0, 'DefaultAxesYGrid',      'off');
set(0, 'DefaultAxesZGrid',      'off');
set(0, 'DefaultLegendBox',      'off');   % 图例无边框
set(0, 'DefaultAxesFontName',   'Microsoft YaHei');  % 含中文时；纯英文可删
```

规则（逐项对标 Python）：
- 仅保留左 + 下坐标轴脊线（`Box off`），关闭网格
- 线宽 ≥ 1.5，坐标轴脊线 0.8，刻度朝外（`TickDir out`）
- 字号层次：轴标签 8、刻度 6.5、图例 6.5、线宽 1.5
- 语义化颜色：连续量用 `parula` / `viridis`，分类用 `lines` 或灰色系；**禁止使用默认 `jet`**
- 图例无边框
- 纯中文标签须指定中文字体（如 `'FontName','Microsoft YaHei'`）；若 `Box off` 在个别版本仍残留右上边框，显式 `ax = gca; ax.Box = 'off';`

### MATLAB 文本与公式渲染规范（仅极个别 MATLAB 出图例外时适用）

MATLAB 标题/标签/图例文本默认解释器为 `'tex'`，而 `'tex'` 与 `'latex'` 解释器**只认 ASCII 加特定 TeX 命令，不认 Unicode 数学符号**。若直接写入 `·`（U+00B7）、`×`（U+00D7）、`−`（U+2212）、`≈`、`α` 等字符，会渲染为空白/方块或令整段公式失败；即便改用 `'latex'` 解释器也无效（MATLAB 的 latex 是阉割版，不加载宏包，同样拒绝原始 Unicode）。

规则：
- 含数学公式的标签/标题/图例必须显式设置 `Interpreter='latex'`
- 公式一律用 TeX 命令书写，**禁止**直接写 Unicode 数学符号：
  - 乘号 `·` / `×` → `\cdot` / `\times`
  - 减号 `−`（U+2212）→ 用 ASCII 连字符 `-`（`latex` 下正确渲染为减号）
  - 希腊字母 `α β γ θ` → `\alpha \beta \gamma \theta`
  - 函数名 `sin cos exp log` → `\sin \cos \exp \log`（带正确间距）
  - 上下标用花括号：`e^{-0.1x}`、`x_{i}`
- **中文绝不可放进 `latex` 解释器字符串**：一条文本只能由一种解释器处理，哪怕中文只是前缀（如 `'理论包络 $...$'`），一旦整体标 `Interpreter='latex'`，中文会导致整串报"必须具备有效的解释器语法"而无法渲染。
- 需要"中文 + 公式"同处时，**拆成两个独立 text 对象**：中文部分用默认 / `'none'` 解释器并指定中文字体；数学公式部分单独用 `latex`。
- 纯中文/英文标签无需 `latex`，但须确认已设置中文字体（见下），否则显示为方框
- 中文字体：MATLAB 默认不含中文字体，标题/标签含中文时须指定支持中文的字体（如 `'FontName','Microsoft YaHei'`）

示例（纯公式）：
```matlab
xlabel('x', 'Interpreter', 'latex');
title('$f(x)=e^{-0.1x}\cdot\sin(x)$', 'Interpreter', 'latex');
ylabel('$A$', 'Interpreter', 'latex');
```

示例（中文 + 公式，必须拆分）：
```matlab
% 中文走默认解释器 + 中文字体
text(x0, y0, '理论包络', 'FontName', 'Microsoft YaHei');
% 公式单独走 latex，用独立 text 对象定位到中文右侧
text(x1, y1, '$\pm e^{-0.1x}$', 'Interpreter', 'latex');
```

## 八、常见可视化问题排查

### 问题 1：Matplotlib 字体回退警告（最常见）

**表现**：
```
Font 'default' does not have a glyph for '\u2212' [U+2212], substituting with a dummy symbol.
UserWarning: Glyph XXXX missing from font(s) DejaVu Sans
```

**原因**：Matplotlib 默认字体 DejaVu Sans 缺少 U+2212（真正的减号）和 CJK 中文字形。当图表标题/标签包含中文或数学符号时触发。

**影响**：中文显示为空白方框 `□□`，减号被替换为虚拟符号。

**修复方法**：

- **方法一：验证系统字体是否被正确加载**
```python
import matplotlib.font_manager as fm

# 检查系统中是否包含中文字体
chinese_fonts = [f.name for f in fm.fontManager.ttflist
                 if any(k in f.name for k in ['Hei', 'YaHei', 'Song', 'Fang', 'Kai', 'CJK'])]
print(chinese_fonts)
# 期望输出至少包含: ['SimHei', 'Microsoft YaHei']
# 如果为空 → 系统缺少中文字体，需要安装
```

- **方法二：使用 fontproperties 直接指定字体路径（最可靠）**
```python
from matplotlib.font_manager import FontProperties

# 方法 A：通过字体名称指定（需注册在系统中）
font_cn = FontProperties(family='SimHei', size=8)

# 方法 B：通过字体文件路径指定（无需注册，最可靠）
# Windows: C:/Windows/Fonts/simhei.ttf
# macOS: /System/Library/Fonts/PingFang.ttc
# Linux: /usr/share/fonts/truetype/...
font_cn = FontProperties(fname='C:/Windows/Fonts/simhei.ttf', size=8)

ax.set_title('中文标题', fontproperties=font_cn)
ax.set_xlabel('迭代次数', fontproperties=font_cn)
```

- **方法三：强制全局修改字体回退**
```python
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'DejaVu Sans']
plt.rcParams['axes.unicode_minus'] = False   # 解决 U+2212 警告
```

### 问题 2：Polyfit 病态条件警告（调试过程）

**表现**：
```
RankWarning: Polyfit may be poorly conditioned
```

**原因**：使用 15 阶以上多项式拟合大量数据点时，Vandermonde 矩阵条件数过大，数值不稳定。

**处理原则**：
- 这是调试过程中的尝试性警告，不代表最终方案有问题
- 如果最终方案不涉及高阶多项式拟合，**直接忽略此警告**
- 如果确实需要多项式拟合：
  - 降低多项式阶数（≤ 10）
  - 使用 `numpy.polynomial.Polynomial.fit()` 替代 `polyfit`（数值更稳定）
  - 改用样条插值（`scipy.interpolate`）

### 问题 5：MATLAB 公式/符号渲染为空白、方块或报"必须具备有效的解释器语法"

**表现**：图标题/坐标轴标签里的 `·`、`×`、`−`、`α` 显示为空或方块；或报 `字符串标量或字符向量必须具备有效的解释器语法` 且对应文字（SceneNode）创建失败、不显示。

**原因**：MATLAB 文本解释器（`'tex'` 默认，或 `'latex'`）只接受 ASCII 与 TeX 命令。两类典型错误：
- 直接写入 Unicode 数学符号（`·` `×` `−` `≈` `α` 等）→ 渲染为空白/方块；
- 把**中文**放进 `latex` 解释器字符串（哪怕只是前缀，如 `'理论包络 $...$'`）→ 整串非法，报"必须具备有效的解释器语法"。一条文本只能由一种解释器处理，中文无法在 `latex` 下解析。

**修复**：
- 含公式处加 `Interpreter='latex'`，并将 Unicode 数学符号替换为 TeX 命令：`\cdot`、`\times`、`\alpha`、`\sin` 等；减号用 ASCII `-`
- **中文绝不进 `latex` 解释器**；需要"中文 + 公式"时拆成两个独立 text 对象（中文用默认 / `'none'` + `'FontName','Microsoft YaHei'`，公式单独 `latex`）
- 纯中文标签指定中文字体 `'FontName','Microsoft YaHei'`
